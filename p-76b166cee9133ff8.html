  • A. Appendix


      • A.1 Default MIDI Mappings

        • These diagrams identify the default messages sent by Custom Modes and Programmer Mode.


          • A.1.1 Custom 1

            • Eight vertical unipolar faders send CC 7–14.
            • A.1.1 — Custom 1 default mapping


          • A.1.2 Custom 2

            • Eight horizontal bipolar faders send CC 15–22.
            • A.1.2 — Custom 2 default mapping


          • A.1.3 Custom 3

            • The 8 × 8 grid sends momentary notes in four 4 × 4 drum areas.
            • A.1.3 — Custom 3 default mapping


          • A.1.4 Custom 4

            • The 8 × 8 grid sends momentary notes in a chromatic keyboard layout.
            • A.1.4 — Custom 4 default mapping


          • A.1.5 Custom 5

            • The 8 × 8 grid sends Program Changes 0–63.
            • A.1.5 — Custom 5 default mapping


          • A.1.6 Custom 6

            • The diagram assigns Program Changes 64–127 to the 8 × 8 grid.

            • Note/Info The guide’s A.1.6 heading calls this “Momentary Note On,” while its diagram labels every pad PRG 64–127. Launchpad/UG/08 Custom Modes/02 Default Custom Modes also describes Custom 6 as Program Change 64–127.

            • A.1.6 — Custom 6 default mapping


          • A.1.7 Custom 7

            • The 8 × 8 grid sends momentary notes in the drum-style map.
            • A.1.7 — Custom 7 default mapping


          • A.1.8 Custom 8

            • The 8 × 8 grid sends momentary notes in the Programmer Mode-style map.
            • A.1.8 — Custom 8 default mapping


          • A.1.9 Programmer Mode

            • The full surface, including outer buttons and logo LED, has MIDI note addresses.
            • The Programmer’s Reference Guide has the full MIDI implementation.
            • A.1.9 — Programmer Mode default mapping


      • A.2 Overlap Layouts

        • The diagrams compare how repeated notes fall across Chromatic and Scale layouts.


          • A.2.1 Overlap – Five Finger

            • Five-finger overlap repeats the leftmost notes of an upper row toward the right of the row below.
            • A.2.1 — Five Finger overlap in Chromatic and Scale Modes


          • A.2.2 Overlap – Four Finger

            • Four-finger overlap repeats notes across rows with a shorter horizontal reach.
            • A.2.2 — Four Finger overlap in Chromatic and Scale Modes


          • A.2.3 Overlap – Sequential

            • Sequential overlap places notes linearly in Chromatic Mode and repeats only root octaves in Scale Mode.
            • A.2.3 — Sequential overlap in Chromatic and Scale Modes
