Microfreak/UG/04 Presets/03 Preset Config

  • 04.03 Tweaking the Preset Configurations

    • Utility contains settings that change how the current preset behaves. Each preset saves its own settings, so presets can differ in voice mode, pressure response, sequence length, and other behavior.

    • Note/Info The two sequences in a preset always have the same length.

    • Changing Utility > Preset settings can reshape a sequence. For example, change Glide Mode from Time to Rate, turn on Envelope Reset for a snappier sequence, or change Seq (1–4) Smooth to hear how smoothing affects its mood.
    • The following preset parameters can be edited in Utility. None can be edited in MIDI Control Center.

    • Voice

      • Bend Range [0–24]: Sets the range from zero to two octaves.
      • Glide Mode [Time, Sync, Rate]: Selects time-based, tempo-synced, or rate-based glide for the Glide knob.
      • Unison Spread [0.001–12.000]: Sets the spread between the four voices.
      • Unison Count [2–4]: Sets how many voices take part in Unison mode.

    • Modulations

      • Envelope Legato [Off, On]: Resets the envelope on a keyboard trigger.
      • Envelope Snap [Off, On]: Creates a sharper envelope decay.
      • LFO Retrig [Off, On, Legato]: Sets whether the LFO retriggers, retriggers on a keyboard trigger, or does not retrigger during legato playing.
      • Press Mode [Aftertouch, Velocity]: Selects the pressure mode.
      • Key/Arp Mode [Linear, Random]: In Random mode, generates a new random value for each key pressed.
      • Velo Amp Mod [0–10]: Sets how velocity affects the output volume.

    • Preset Volume

      • Preset Volume [−12 to +12]: Sets the preset's relative volume.

    • Scale

      • Scale: Selects Global, Off, Major, Minor, Harmominor, Dorian, Mixolydian, Blues, or Penta.
      • Root Note: Selects C, C♯, D, D♯, E, F, F♯, G, G♯, A, A♯, or B.

    • Seq/Arp

      • Seq Length [4–64]: Sets the sequence length.
      • Default Gate Length [5–85]: Sets the default sequencer or arpeggio gate length; the default is 45.
      • Seq 1 Smooth [Off, On]: Smooths the sequencer MOD track 1.
      • Seq 2 Smooth [Off, On]: Smooths the sequencer MOD track 2.
      • Seq 3 Smooth [Off, On]: Smooths the sequencer MOD track 3.
      • Seq 4 Smooth [Off, On]: Smooths the sequencer MOD track 4.

    • Vocoder

      • Vocoder Hiss Mode [Off, Switched, Pass]: Sets whether hiss is heard while using the vocoder.
      • Vocoder Hiss Volume [−20 to 0]: Sets the vocoder hiss volume.
