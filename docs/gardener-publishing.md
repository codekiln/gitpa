# Publish Ghost in the Patch

The website is generated by [Logseq Gardener](https://github.com/codekiln/logseq-gardener). The checked-in `gitp-garden` and podcast RSS remain the publication sources.

Install the pinned tools with `mise install` and the parser dependency with `npm ci`. Build `lsg` from the renderer revision pinned in the Pages workflow, then generate a fresh output directory:

```sh
python3 scripts/build_site.py --renderer /absolute/path/to/lsg --output /private/tmp/gitpa-preview
python3 -m http.server --directory /private/tmp/gitpa-preview 8765
```

Open [the preview homepage](http://localhost:8765/). The home page retains the introduction, subscription link, fly artwork, and Recent Ceremonies list. The build evaluates the authored Logseq query, result transform, and Hiccup view through the same parser used by `site:query:check`; the prepared publication graph receives ordinary links in the evaluated order. The source query stays in the garden. An unsupported query view or a result linking to a missing or unpublished page stops publication.

The light Nord stylesheet applies to the homepage, episode pages, and reference pages. Logseq Gardener renders page and block transclusions and recording controls. Episode preparation continues to select public notes and derive asset visibility from published episodes. The build includes explicitly public pages, copies the existing RSS, and adds the GitHub Pages `.nojekyll` marker. The generated All pages index supplies a redirect map for existing `#/page/...` episode links, including links already distributed in RSS.

Run `python3 -m unittest discover -s tests`, `mise run site:query:check`, and `mise run rss:check` before publication. Review the generated homepage, an episode with chapter audio and waveforms, and an instrument manual with transclusions. PR builds upload the complete `gitpa-website` preview; merging publishes the same output to GitHub Pages.
