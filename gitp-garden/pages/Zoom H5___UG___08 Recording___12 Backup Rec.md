- # Backup recording
	- Backup recording works only with the L/R input and with 44.1 kHz or 48 kHz WAV formats.
	- Along with the normal recording, the H5 records a second file from the L/R input at a level 12 dB lower. If the main recording distorts because the level was set too high, the backup can be used instead.
	- 1. Press **MENU**, then use the scroll button to select `REC > In L/R BACKUP`.
	- 2. Select `ON`, then press the scroll button.
	- > [[Note/Info]] The backup file takes the original name with `_BU` added. A recording named `ZOOM0001_TrLR.wav` gets the backup `ZOOM0001_TrLR_BU.wav`.
	- > [[Note/Info]] No backup file is created if the L/R input is not selected.
	- > [[Note/Info]] The `LO CUT` and `COMP/LIMITER` settings do not affect the backup recording.
	- > [[Note/Info]] To play a backup, select and play the file whose name ends in `_BU`. In MULTI FILE mode, assign it to a track as described under "Assigning files to tracks" in [[Zoom H5/UG/08 Recording/13 Overdubbing]]. In STEREO FILE mode, pick it from the file list: [[Zoom H5/UG/09 Playback/02 Select from Lists]].
	- > [[Note/Info]] Backup recording uses more SD card space.
