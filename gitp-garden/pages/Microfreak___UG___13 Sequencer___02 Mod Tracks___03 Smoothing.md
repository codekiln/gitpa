- # 13.2.3. Smoothing
	- Smoothing, or slew, makes changes between stored modulation values gradual, much as Glide smooths changes in pitch. Set each track separately in Utility > Preset > Seq (X) smooth, where X is the modulation track number from 1 to 4.
	- A new track recorded step by step has smoothing off by default. A new track recorded in real time has smoothing on by default. Overwriting an existing track keeps its smoothing setting.
