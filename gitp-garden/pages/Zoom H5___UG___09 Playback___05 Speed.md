- # Changing the playback speed
	- Playback speed can be set from 50% to 150% of normal.
	- 1. Press **MENU**, then use the scroll button to select `PROJECT` (MULTI FILE mode) or `FILE LIST` (STEREO FILE mode).
	- 2. Use the scroll button to select the project or file to adjust, then press the scroll button.
	- 3. Use the scroll button to select `OPTION > PLAYBACK SPEED`.
	- 4. Move the scroll button up or down to set the speed, then press the scroll button.
		- Playback speed screen
			- ![01 Playback speed screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___09%20Playback___05%20Speed___Asset___01-Playback-speed-screen.png)
		- The range is `50%` to `150%`.
		- Playback uses the new speed. The speed can be changed during playback; the lower-left corner shows whether playback is playing or paused.
		- **MENU** cancels.
	- > [[Note/Info]] In MULTI FILE mode, each project keeps its own speed setting. In STEREO FILE mode, one setting applies to every file.
	- > [[Note/Info]] `PLAYBACK SPEED` is disabled on the `MIXER/OVERDUB` screen.
