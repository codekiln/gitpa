- # [42.13 Grid Snapping and Drawing](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#grid-snapping-and-drawing)
	- Toggle Draw Mode (Pitch Lock Off) — `B`
	- Narrow Grid — `Cmd+1` (Win `Ctrl+1`)
	- Widen Grid — `Cmd+2` (Win `Ctrl+2`)
	- Triplet Grid — `Cmd+3` (Win `Ctrl+3`)
	- Snap to Grid — `Cmd+4` (Win `Ctrl+4`)
	- Fixed/Zoom-Adaptive Grid — `Cmd+5` (Win `Ctrl+5`)
	- Bypass Snapping While Dragging — `Cmd` (Win `Alt`)
