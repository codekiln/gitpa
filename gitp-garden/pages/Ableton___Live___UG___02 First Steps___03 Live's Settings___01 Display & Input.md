- # [2.3.1 Display & Input](https://www.ableton.com/en/live-manual/12/first-steps/#display--input)
	- Language and zoom for the main window, a second window and the Settings window.
	- Display Options: "Outline View in Focus" draws a border around the selected view; scroll bar style; Follow behavior for Arrangement View and clips; interface labels.
	- Navigation and Keyboard: Tab key focus movement, continuous Tab navigation within a section, and moving clips with the arrow keys.
	- Mouse and Pen Input: Pen Tablet Mode, permanent scrub areas, and pitch-locked drawing for MIDI notes.
	- Application Options restores "Don’t Show Again" warnings you switched off.
