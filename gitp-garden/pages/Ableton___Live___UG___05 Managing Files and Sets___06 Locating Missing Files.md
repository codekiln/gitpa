- # [5.6 Locating Missing Files](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#locating-missing-files)
	- When a Set, clip or preset references missing files, the Status Bar warns, affected clips and sample slots show "Offline", and they play silence.
	- Click the warning to open the File Manager's missing-file list (Manage Files → Manage Set → Locate).
