- # Changing the playback pitch (key)
	- The pitch can change while the playback speed stays the same.
	- 1. Press **MENU**, then use the scroll button to select `PROJECT` (MULTI FILE mode) or `FILE LIST` (STEREO FILE mode).
	- 2. Use the scroll button to select the project or file to adjust, then press the scroll button.
	- 3. Use the scroll button to select `OPTION > KEY CONTROL`.
		- > [[Note/Info]] In MULTI FILE mode, the pitch change applies to the whole project. It cannot be set for each track.
	- 4. Move the scroll button up or down to set the pitch, then press the scroll button.
		- Key control screen
			- ![01 Key control screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___09%20Playback___04%20Pitch___Asset___01-Key-control-screen.png)
		- The range is `♭6` to `♯6`.
		- Playback uses the new pitch. The pitch can be changed during playback; the lower-left corner shows whether playback is playing or paused.
		- **MENU** cancels.
	- > [[Note/Info]] In MULTI FILE mode, each project keeps its own pitch setting. In STEREO FILE mode, one setting applies to every file.
	- > [[Note/Info]] `KEY CONTROL` is disabled on the `MIXER/OVERDUB` screen.
