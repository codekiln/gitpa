- # Trimming project beginnings and ends
	- Cut unwanted material from the start and end of a recording. Set the starting and ending points of the part to keep.
	- 1. Press **MENU**, then use the scroll button to select `PROJECT` (MULTI FILE mode) or `FILE LIST` (STEREO FILE mode).
	- 2. Select the project or file to trim, then select `EDIT > TRIM`.
	- 3. Use the scroll button to select the starting point icon.
		- Trim screen
			- ![01 Trim screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___10%20Project%20and%20File%20Editing___08%20Trim___Asset___01-Trim-screen.png)
		- The line under the bar shows the starting time and ending time of the part to keep.
	- 4. Use **Back** and **Forward** to find the starting point.
		- > [[Note/Info]] Press **PLAY/PAUSE** to search while the recording plays.
	- 5. Use the scroll button to select the ending point icon, then set the ending point the same way.
	- 6. Press **REC**.
	- 7. Select `YES`.
	- > [[Note/Info]] If a track holds several recordings, including overdubs, only the file currently selected for that track is trimmed.
