- # [5.7 Collecting External Files](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#collecting-external-files)
	- Collecting copies external files into the Project folder so moved originals can't break the Set.
	- File → Collect All and Save asks which locations to collect from. Packs and the User Library need collecting only if you plan to move or uninstall them; collecting multisampled instruments can make the Project much larger. Files go into the Project's Samples or Presets folders.
	- In the File Manager (Manage Set), the External Files section groups files outside the Project by location with counts and sizes. Show displays them in the browser; toggle Collect Into Project per location, then press Collect and Save.
