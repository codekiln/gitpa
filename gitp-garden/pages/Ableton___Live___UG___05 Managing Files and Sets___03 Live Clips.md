- # [5.3 Live Clips](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#live-clips)
	- A Live Clip ([[Ableton/File/.alc]]) saves one audio or MIDI clip for reuse. Audio Live Clips only reference their samples, so they stay small.
	- Drag a clip into the Current Project or a user folder in Places to save it; Collect Files on Export decides whether the sample is copied. Name it and press `Enter`.
	- A Live Clip keeps the clip, its envelopes and the original track's devices. The devices return only when you drop it on an empty track or into empty space; on a track with devices, only the clip settings load.
	- Clips inside any saved Live Set also count as Live Clips (see Merging Sets).
	- Default clip settings in an `.asd` describe how a sample should load. Live Clips are separate musical ideas: several variations of one sample, each with its own warp, pitch, envelopes and effects, can be stored and previewed side by side.
