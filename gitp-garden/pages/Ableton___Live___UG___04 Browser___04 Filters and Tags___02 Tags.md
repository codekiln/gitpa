- # [4.4.2 Tags](https://www.ableton.com/en/live-manual/12/working-with-the-browser/#tags)
	- Tags help find, organize and discover content. All factory content from the Core Library and bundled Packs carries descriptive tags; third-party Packs from the Ableton shop are tagged in the Sounds group.
	- Factory tags can't be removed, but you can add other tags, including your own, in the Tag Editor.
	- Background sound analysis auto-tags user samples up to 60 seconds long with the best-matching tag. Turn this off with Enable Auto Tags in the Filter View menu, or change or remove auto tags in the Tag Editor.
	- VST3 plug-ins get tags from their VST sub-category when it maps to one of Live's categories.
