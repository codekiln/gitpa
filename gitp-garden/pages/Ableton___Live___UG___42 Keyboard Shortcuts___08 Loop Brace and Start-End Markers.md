- # [42.8 Loop Brace and Start/End Markers](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#loop-brace-and-startend-markers)
	- Set Start Marker — `Cmd+F9` (Win `Ctrl+F9`)
	- Set Loop Brace Start — `Cmd+F10` (Win `Ctrl+F10`)
	- Set Loop Brace End — `Cmd+F11` (Win `Ctrl+F11`)
	- Set End Marker — `Cmd+F12` (Win `Ctrl+F12`)
	- With the loop brace or the start or end marker selected:
		- Move Start Marker to Position — `Cmd` click (Win `Ctrl` click)
		- Move End Marker to Position — `Cmd+Shift` click (Win `Ctrl+Shift` click)
		- Nudge Loop Brace Left/Right — right and left arrow keys
		- Move Loop by Loop Length — up and down arrow keys
		- Halve/Double Loop Length — `Cmd` up and down arrow keys (Win `Ctrl` up and down arrow keys)
		- Shorten/Lengthen Loop — `Cmd` right and left arrow keys (Win `Ctrl` right and left arrow keys)
		- Select Material in Loop — `Cmd+Shift+L` (Win `Ctrl+Shift+L`)
