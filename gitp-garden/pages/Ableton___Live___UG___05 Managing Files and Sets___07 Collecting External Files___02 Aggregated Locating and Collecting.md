- # [5.7.2 Aggregated Locating and Collecting](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#aggregated-locating-and-collecting)
	- The File Manager can locate and collect files for the User Library, the current Project, and other Projects, not just the open Set. Use Manage User Library or Manage Project, or right-click a Project folder in the browser and choose Manage Project. Finish with Collect and Save.
