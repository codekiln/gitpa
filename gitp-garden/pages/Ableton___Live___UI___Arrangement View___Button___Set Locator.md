- # Set Locator button
	- Adds a locator to the [[Ableton/Live/UI/Arrangement View/Scrub Area]] at the play position during playback or recording; with the transport stopped, at the insert marker or the start of the time selection.
	- When a locator is selected, the button becomes the Delete Locator button.
	- **Behavior** — trigger. New locators are quantized to the global launch quantization.
	- **Remote control** — MIDI or key mapping. [[Ableton/Manual/06/03 Launching the Arrangement with Locators]] keeps a suggested key for it.
