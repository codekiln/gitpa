- # [34.2.5 Computer Keyboard Remote Control](https://www.ableton.com/en/live-manual/12/midi-and-key-remote-control/#computer-keyboard-remote-control)
	- ![The Key Map Mode Switch](https://ableton-production.imgix.net/live-manual/12/KeyMapModeSwitchL12.png?auto=&w=320)
	- 1. Turn on Key Map Mode with the **KEY** switch in the upper right corner (`Cmd+K` on Mac, `Ctrl+K` on Windows). Mappable controls turn red and the Mapping Browser appears.
	- 2. Click the control to map; only controls with a red overlay can be mapped.
	- 3. Press the computer key to assign. The mapping appears in the Mapping Browser.
	- 4. Press KEY again to leave Key Map Mode.
	- Mapped keys work like MIDI notes: slots follow their Launch Mode, switches flip, and radio buttons step through their options.
	- Key mapping is different from the computer MIDI keyboard, which turns keystrokes into MIDI notes for instruments.
	- Suggested key mappings for locators: [[Ableton/Manual/06/03]]
