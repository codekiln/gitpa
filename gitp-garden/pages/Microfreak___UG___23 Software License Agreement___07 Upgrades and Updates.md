- # 7. Upgrades and Updates
	- Using an upgrade or update requires a valid license for the previous or lower software version. Transferring that version to a third party ends the right to use its upgrade or update.
	- Acquiring an upgrade or update alone grants no right to use the software. Installing one ends support rights for the previous or lower version.
