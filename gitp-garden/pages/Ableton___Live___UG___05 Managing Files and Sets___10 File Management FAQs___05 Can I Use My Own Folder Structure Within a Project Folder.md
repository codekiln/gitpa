- # [5.10.5 Can I Use My Own Folder Structure Within a Project Folder?](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#can-i-use-my-own-folder-structure-within-a-project-folder)
	- Yes, then relink with the File Manager:
		- Reorganize the folder in the browser or the operating system.
		- Choose Manage Project from the folder's context menu in the browser.
		- If Missing Samples shows moved files, press Locate, open Automatic Search, turn on Search Project and Fully Rescan Folders, and press Go.
		- Press Collect and Save to update the Project.
