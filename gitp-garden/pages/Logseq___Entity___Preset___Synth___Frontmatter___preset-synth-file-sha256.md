- # Preset File Digest
	- Owning type: [[Logseq/Entity/Preset/Synth]].
	- The 64 lowercase hexadecimal characters of SHA-256 computed over the exact bytes linked by [[Logseq/Entity/Preset/Synth/Frontmatter/preset-synth-file]]. Omit until the file exists.
	- A digest detects changes to that file. Equivalent sounds can have different export bytes, so a digest does not prove musical equivalence.
