- # [34.2.2 Mapping to MIDI Notes](https://www.ableton.com/en/live-manual/12/midi-and-key-remote-control/#mapping-to-midi-notes)
	- A mapped MIDI note sends Note On and Note Off to the control:
		- **Session View slots** — clips respond according to their Launch Mode.
		- **Switches** — each Note On flips the switch.
		- **Radio buttons** — each Note On steps to the next option.
		- **Variable parameters** — one note flips the parameter between its Min and Max. A range of notes spreads evenly spaced values across the parameter's range, one per note.
	- A slot can be mapped to a note range for playing a clip chromatically: press the root key (default transposition), and while holding it, press one key below and one above to set the range limits.
