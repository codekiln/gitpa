- # Sym (BasicWaves)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Timbre]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/BasicWaves]].
	- Morphs between square-wave pulse width and phasing between the two sawtooth copies. It has no effect when Wave is at 50 (sawtooth).
