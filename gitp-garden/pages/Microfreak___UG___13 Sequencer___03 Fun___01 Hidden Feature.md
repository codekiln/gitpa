- # 13.3.1. A Hidden Feature
	- Patterns A and B share the effects of their modulation tracks when you switch between them. Suppose A changes oscillator type on steps one and four. If you switch to B after step four, B starts with the oscillator type last set by A; switching before step four leaves B with the type set on step one.
	- > [[Note/Info]] To make more patterns that use the same sound, copy a preset and record new patterns in the copy. Switching presets gives access to the patterns and modulation tracks in each.
	- > [[Note/Info]] The following ideas can also be used with the arpeggiator. The Matrix can both route and mix signals when shaping sequences and arpeggios.
