- # [42.25 Momentary Latching Shortcuts](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#momentary-latching-shortcuts)
	- Holding some shortcut keys for about 500 ms toggles their action only while held; releasing the key restores the previous state:
		- `A` — Arrangement automation mode
		- `B` — Draw Mode
		- `S` — solo the selected track
		- `Z` — zoom to the Arrangement selection
		- `F1`…`F8` — Track Activator for the first eight tracks
		- `Tab` — Arrangement or Session View
	- The Options.txt entry `-DisableHotKeyLatching` turns latching off.
