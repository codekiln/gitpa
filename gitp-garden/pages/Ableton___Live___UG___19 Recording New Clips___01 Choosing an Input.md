- # [19.1 Choosing an Input](https://www.ableton.com/en/live-manual/12/recording-new-clips/#choosing-an-input)
	- A track records whatever input its In/Out section shows (View → In/Out). In Arrangement View, unfold and enlarge the track to see all of it.
		- ![The track In/Out section in Arrangement (left) and Session View (right)](https://ableton-production.imgix.net/live-manual/12/TrackInOutSectionL12.png?auto=&w=320)
	- By default an audio track records mono from external input 1 or 2, and a MIDI track records all incoming MIDI from active input devices. The computer MIDI keyboard works when no controller is attached.
	- Any track can instead record another mono or stereo input, one channel of one MIDI device, or another track; see [[Ableton/Live/UG/17 Routing and IO]].
