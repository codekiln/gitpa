- # Inv/Transp (Chords)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Timbre]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/Chords]].
	- Changes the chord inversion and frequency range. The chord stays the same, but the pitches are combined differently as the Timbre knob moves or is modulated externally.
