- # [31.13.4 Filters](https://www.ableton.com/en/live-manual/12/live-instrument-reference/#filters-2)
	- The same filter types and Cytomic circuits as Operator (Clean, OSR, MS2, SMP, PRD), with **Frequency**, **Resonance**, **Drive** and **Morph**; drag the filter dots in the display. See [[Ableton/Live/UG/31 Instrument Reference/09 Operator/05 Filter Section]].
		- ![Wavetable's Filters](https://ableton-production.imgix.net/live-manual/12/WavetableFiltersL12.png)
	- Routing:
		- **Serial** — all oscillators into Filter 1, then Filter 2; Sub to both.
		- **Parallel** — the main oscillators into both filters; Sub to both.
		- **Split** — Osc 1 to Filter 1, Osc 2 to Filter 2, Sub half to each. An oscillator stays audible if its filter is off. Good for layered sounds, or for treating only the Sub when the main oscillators are off.
