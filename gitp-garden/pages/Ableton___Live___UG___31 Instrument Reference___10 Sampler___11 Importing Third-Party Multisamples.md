- # [31.10.11 Importing Third-Party Multisamples](https://www.ableton.com/en/live-manual/12/live-instrument-reference/#importing-third-party-multisamples)
	- Formats: REX files (Live Standard and Suite only), ACID Loops and Soundtrack Loops. Their tags aren't available in Live.
	- Drag a file from the browser into a Set to import it into the User Library; presets appear under User Library/Sampler/Imports. Some become Instrument Racks holding several Samplers to match the original.
