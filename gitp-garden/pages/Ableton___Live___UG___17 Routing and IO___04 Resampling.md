- # [17.4 Resampling](https://www.ableton.com/en/live-manual/12/routing-and-i-o/#resampling)
	- Choosing **Resampling** as an audio track's Input Type records Live's Main output into that track.
	- Uses: turn the current mix into a new sample, print processor-heavy tracks so their devices can be removed, or preview a mix before rendering.
	- Keep the Main meter as high as possible without hitting red, arm the track and record into an empty slot. The recording track's own output is left out.
	- Recordings go to the Project's Samples/Recorded folder, or the Temporary Folder until the Set is saved.
