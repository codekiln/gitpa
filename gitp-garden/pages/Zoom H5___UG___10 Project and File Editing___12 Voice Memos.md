- # Adding voice memos
	- MULTI FILE mode only. Record a spoken memo and attach it to a project.
	- 1. Press **MENU**, then use the scroll button to select `PROJECT`.
	- 2. Select the project for the memo, then select `OPTION > VOICE MEMO`.
	- 3. Record the memo.
		- Voice memo screen
			- ![01 Voice memo screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___10%20Project%20and%20File%20Editing___12%20Voice%20Memos___Asset___01-Voice-memo-screen.png)
		- Press **REC** to start recording.
		- Press **STOP** or **REC** to stop recording.
	- 4. Play the memo.
		- Press **PLAY/PAUSE** to start playback.
		- Press **STOP** to stop playback.
	- > [[Note/Info]] Each new recording with **REC** overwrites the voice memo.
	- > [[Note/Info]] Voice memos record from the stereo mic connected to the L/R inputs. They cannot be recorded from Inputs 1/2.
	- > [[Note/Info]] The memo file is named in the form `ZOOM0001_VM` and recorded as 128 kbps MP3.
