# Prototype: Marginalia

An open parchment medallion with a rubricated initial, botanical vines and tiny hand-drawn radio waves. A page-seeded flower palette and a little spirit or eye vary between episodes. The loose edges evoke marks made in a manuscript margin.

This experiment is for [issue #164](https://github.com/codekiln/gitpa/issues/164); it only alters the local preview server, never the published site.

Build a site as described in [the publishing guide](../../docs/gardener-publishing.md), then run:

```sh
python3 site/prototype-marginalia/preview.py /private/tmp/gitpa-preview
```

Open [Infini Pad at the Crossfader](http://localhost:8767/gitpa/GitP/A/Session/26/11/06-Fri/) and navigate to other episodes or change appearance. The server expects the generated `gitpa` directory inside the specified parent.
