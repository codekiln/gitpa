2026-09-28 Mon / Project - move the sections of the Microfreak user guide in the UG subnamespace

  • When I requested that AI import the Logseq/Entity/Book/Sections for the microfreak user guide, it was one of the first times I prototyped that section, and I instructed AI to put it inside of Microfreak, for example, Microfreak/08 LFO was a direct child of the parent namespace. Placing guide sections directly under Microfreak made the user guide difficult to reference in the abstract. I changed this in Launchpad/UG, where UG stood for User Guide. The section is now Microfreak/UG/08 LFO.
