Microfreak/Preset/259 Infini Pad

Page reference

  • Saved export: read from the device's slot 259 over USB on October 25, 2026 with mise run microfreak:download --slot 259. Two consecutive reads returned the same file.
  • The parameter payload matches the MIDI Control Center archives Factory 3.0, Factory 6.0 (Factory 3.0 slot 326, Factory 6.0 slot 19). Comparison used mise run microfreak:compare.
  • Download the slot 259 capture. It is the raw device format (header plus data packets), not an .mbp file; see Microfreak/Preset/259 Infini Pad/Asset/Device-Read-2026-10-25/bin.
  • The saved-parameter inspector preserves the original fields. Oscillator interpretation assumes the documented firmware 5 layout; firmware is not detected from the export.
  • Matrix assignments follow the Freakout live map. Mode, LFO shape, filter type and octave labels follow the MicroFreak Reader definitions.
Microfreak/Preset/260 8bitfi

Page reference

  • Saved export: read from the device's slot 260 over USB on October 25, 2026 with mise run microfreak:download --slot 260. Two consecutive reads returned the same file.
  • The parameter payload matches the MIDI Control Center archives Factory 3.0, Factory 6.0 (Factory 3.0 slot 327, Factory 6.0 slot 177). Comparison used mise run microfreak:compare.
  • Download the slot 260 capture. It is the raw device format (header plus data packets), not an .mbp file; see Microfreak/Preset/260 8bitfi/Asset/Device-Read-2026-10-25/bin.
  • The Assign 3 destination is unresolved. Its saved destination ID is 0x0904, which the Freakout live map lists as an address of the Assign 3 field itself. Assign 3 stores the same ID in 70 of the 384 Factory 6.0 presets. In the session commentary at 21:28, the instrument shows this KEY/ARP → Assign 3 destination as "move".
  • In GitP/A/Session/26/11/01-Sun it was played from the MicroFreak keys from 18:17 to the end, with almost continuous pressure and pitch bends from 22:46. Recorded knob changes covered attack, decay, sustain, the cycling envelope, filter amount, the free LFO rate, Noise and Fold. At 25:15 pressure was routed through Assign 1 to the main envelope's attack, a matrix edit the capture does not record. A read of slot 260 after the session matched the October 25 export, so the slot still holds the factory sound. The session MIDI holds the knob changes as controller messages.
  • The saved-parameter inspector preserves the original fields. Oscillator interpretation assumes the documented firmware 5 layout; firmware is not detected from the export.
  • Matrix assignments follow the Freakout live map. Mode, LFO shape, filter type and octave labels follow the MicroFreak Reader definitions.
