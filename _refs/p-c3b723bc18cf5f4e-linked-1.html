Ableton/Arrangement View/Q/Can I record in Arrangement View while playing Session View clips?

  • Can I record two tracks in Ableton/Arrangement View while I play and record

    • other clips in Session View?
    • Recording a Microfreak on a MIDI track and an audio track into the Arrangement, while launching and recording other Ableton/Clips in Session View.

    • My Answer

      • No. This isn't possible. One can play session clips while arrangement view is playing, but not record into them while recording into arrangement view.
      • 2026-10-26 Mon I've been using Ableton all wrong. I realized I could use Session View to record, or I could use Arrangement Record to record clips and their playback in Session View. See GitP/A/Session/26/10/26-Mon.

    • AI Answer

      • Short answer: yes. Arm the two Microfreak tracks, press Arrangement Record, and keep playing Session clips on other tracks. One caveat: a single track records in one place at a time.
      • Why:
        • Arrangement Record is per track: "Recording creates new clips in all tracks that have their Arm button on" (Recording New Clips).
        • Session clips you launch during the pass are recorded to the Arrangement as well (Automation and Editing Envelopes).
        • With "Start Playback with Record" off, recording starts when you press Play or launch a Session clip. Holding Shift while pressing Arrangement Record flips that behavior.
      • Caveats:
        • A track that is also recording into a Session slot does not also get a separate Arrangement take of the same input. Record the Microfreak in the Arrangement and use Session slots on other tracks. The manual does not spell out what a Session-slot recording does to an armed track during Arrangement Record, so test it before a take that matters.
        • This does not give stacked CC lanes. The knob moves are still MIDI CC data inside the recorded clip, shown one CC at a time in its Envelopes panel. See Ableton/Clip/Q/How can I see all MIDI CC clip envelopes stacked in Arrangement View?.
Ableton/Arrangement View/Q/Is there a way to put a time-synced transcript next to an audio track with words?

Page reference

  • Is there a way to put a time-synced transcript in Ableton/Arrangement View next to an audio track with words?

    • The words could be song lyrics, the dialogue of a video, or spoken word.

    • AI Answer

      • Short answer: Live has no transcript or lyrics lane, but a MIDI track of empty, named clips does the job. Put the MIDI track directly above the audio track and add one clip per line. Each clip's name is the text, and it sits on the timeline exactly where the words are sung or spoken. This works in Live 11 without any add-ons. The work is in getting the timings, and that part can be automated.
      • Lyrics track by hand
        • Create a MIDI track next to the audio track. For each line, select its time range on the MIDI track, insert an empty MIDI clip with Cmd+Shift+M, and rename it with Cmd+R to the line's text.
        • The clips move with edits to the arrangement, and you can read the text while zoomed in.
        • This is the same format AbleSet's lyrics feature reads: "a MIDI track called Vocals +LYRICS that contains one clip per lyrics line", with \ in a clip name for a line break. So a track built this way also works with AbleSet if you ever want a lyrics display on a phone or tablet.
      • Getting timings automatically
        • A transcription app such as Mac/App/MacWhisper (OpenAI/Whisper under the hood) can export a time-stamped .srt subtitle file or .lrc lyrics file from the audio.
        • AbleSet has an LRC Lyrics Track Generator that turns an .lrc file into a Live project with the lyrics track already built. It also has a generator where you paste plain lyrics and tap along to the backing track (docs). Drag the track from that project into your set through the browser. Unconfirmed whether the generators need an AbleSet license. AbleSet itself is paid. Its Intro edition shows one lyrics track, and Standard and Pro show any number.
        • To script it yourself, the Live Object Model has Track.create_midi_clip(start_time, length), which inserts an empty MIDI clip in the Arrangement, and clip names are settable. A short Max for Live or Remote Script routine could read an .srt and build the track. That function arrived in the Live 12.1.10 beta (release notes), so it is not available in Live 11.
        • In Live 11 a script can create named locators instead: set Song.current_song_time, call Song.set_or_delete_cue, then set the new CuePoint.name (Song, CuePoint). Locators appear in the ruler above all tracks rather than next to one track, so they work for one voice but crowd quickly. The tools in the see-also report, such as AbletonOSC, can send these calls from outside Live.
      • For video
        • Burn the subtitles into the picture with ffmpeg -i in.mp4 -vf subtitles=in.srt out.mp4, then drop the video on an audio track in the Arrangement. Live shows it in a floating Video Window as it plays (Working with Video). The captions then stay with the picture even if you never build a lyrics track.
      • Floating text window (paid Max for Live devices, untested)
        • SpaceCue shows the name of the playing clip as a teleprompter, which suits the lyrics track above. Display Lyrics + Slides pages through slides of text or images.
      • What doesn't work: Ableton/Info Text is not tied to a time position. Forum reports say Live does not import the lyric or marker events in a standard MIDI file, so a karaoke .mid file won't bring its words along. Ableton doesn't document this either way.

Ableton/Clip/How To/Clip Same Time Selections Across Multiple Tracks

  • How to Clip the Same Ableton/Arrangement View/Time Selection across Multiple Tracks in Ableton Live

    • Goal

      • Split or create clips with identical time boundaries across multiple tracks in Arrangement View without manually reselecting each track.

    • Preconditions

      • Ableton Live installed and opened in Arrangement View.
      • Basic knowledge of clip selection and keyboard shortcuts.
      • A keyboard available (Mac shortcuts shown; replace Cmd with Ctrl on Windows).

    • Procedure

      • 1. Make your initial time selection

        • In Arrangement View, select the clip or time range on the first track (e.g., Track A).
        • The selection can be an existing audio clip, MIDI clip, or empty time region.
        • For the purposes of instruction, you can make a time selection in a MIDI track and press Keyshort Cmd+Shift+M to create a new empty midi clip.

      • 2. Move the selection to another track

        • If a clip is selected:
          • Press the Up (↑) or Down (↓) arrow keys to move the selection to the track above or below.
          • The time boundaries remain exactly the same.
        • If a time range is selected across the timeline ruler:
          • Press Shift + Up (↑) or Shift + Down (↓) to move the time range selection to another track.

      • 3. Split or create a clip at the same boundaries on the new track

        • If there is an existing clip in the selection range, press Cmd+E to split it at the selection boundaries.
        • If no clip exists, press Cmd+Shift+M to create a new empty MIDI clip with those boundaries.

      • 4. Repeat for additional tracks

        • Continue pressing Up (↑) or Down (↓) to move the selection through tracks.
        • Apply Cmd+E or Cmd+Shift+M on each track as needed.

    • Troubleshooting

      • If the selection doesn’t move tracks as expected, make sure the Arrangement View is active and the correct track is selected.
      • On Windows, replace Cmd with Ctrl for all shortcuts.

    • Tips

      • Select multiple tracks at once by dragging across track headers, then split clips on all selected tracks simultaneously.
      • For faster workflow, alternate between arrow keys and the split/create shortcuts to quickly align clips across many tracks.

    • Outcome

      • You have clips or empty MIDI regions perfectly aligned in time across multiple tracks, ready for further editing, looping, or automation.
Ableton/Clip/How To/Export Multiple Clips to Wav Files

  • How To Batch Export Ableton/Clip/.alc Clips to .wav files in #Ableton Live

    • Goal

      • Export multiple .alc (Ableton Live Clip) files to separate .wav audio files efficiently.

    • Preconditions

      • Ableton Live installed (version 10 or later).
      • .alc clip files available in the Ableton Browser.
      • Familiarity with Arrangement View and Session View.

    • Procedure

      • 1. Manual Render from Arrangement View (Most Reliable)

        • Create a new Ableton Live project.
        • Drag each .alc clip from the Browser into its own track in Arrangement View.
        • Arrange clips sequentially (one after another) if you require a single bounce with individual outputs.
        • Go to File → Export Audio/Video.
          • Set Rendered Track to All Individual Tracks.
          • Choose WAV as File Type.
          • Configure Sample Rate and Bit Depth as desired.
          • Adjust Rendering Options (e.g., disable Normalize).
        • Click Export; Ableton will render each track as a separate .wav named after the track.
        • Tip: Rename tracks to match clip names before exporting for clear file names.

      • 2. Session View Consolidate + Export (Semi-Automated)

        • Load each .alc clip into its own track in Session View.
        • Launch each clip to verify its content.
        • Right-click each clip and choose Consolidate (CMD + J / Ctrl + J).
        • Right-click the consolidated clip and select Show in Finder (macOS) or Show in Explorer (Windows).
          • Locate the .wav file under Project/Samples/Processed/Consolidate.
        • Rename and relocate the .wav files as needed.

    • Troubleshooting

      • Clips not consolidating: Ensure each clip is selected before consolidating.
      • Missing export files: Verify export path in Ableton preferences.

    • References

      • Ableton Live Manual: Export Audio/Video.

Ableton/Clip/Q/How can I see all MIDI CC clip envelopes stacked in Arrangement View?

  • How can I see all the MIDI CC clip envelopes of an Ableton/Clip stacked in Ableton/Arrangement View, like track automation lanes?

    • Recorded a Microfreak into a Session View clip (MIDI and audio) while turning knobs, then dragged the clip into the Arrangement. In the clip's Envelopes panel the MIDI Ctrl chooser shows one CC at a time, but I want every automated CC as its own lane under the track, the way mixer and device automation shows.

    • AI Answer

      • Short answer: as far as the documentation and the UI show, you cannot. MIDI CC data recorded into a clip stays clip-envelope data and has no automation lanes in the Arrangement. This is an inference from the manual plus the track chooser in the screenshot, not something the manual states in one sentence.
      • Why:
        • The manual says "Any automation in Session View becomes track-based automation when clips are recorded or copied into Arrangement View" (Automation and Editing Envelopes). That sentence covers mixer and device parameters.
        • The MIDI track's automation chooser in Arrangement View offers only None and Mixer (plus Show Automated Parameters Only), so there is no MIDI Ctrl entry to show CC lanes.
        • The manual describes MIDI controller data as clip envelopes, chosen with MIDI Ctrl in the clip's Device chooser (MIDI Controller Clip Envelopes). The only place to edit it is the Envelopes panel of the clip.
      • What you can do:
        • Find which CCs have data: in the MIDI Ctrl Control chooser, controllers that already hold recorded data have an LED dot next to the name (manual). In the screenshot that is 12, 13, 23, 24, 26, 28 and 29.
        • Edit one CC at a time in the Envelopes panel of the selected Arrangement clip, as you already do.
        • To get stacked, editable lanes you would need the CC to drive an automatable parameter on a device, for example a Max for Live device that maps incoming CCs to its own parameters. I have not verified that approach.
      • Not settled: whether a newer Live release adds CC lanes to the Arrangement. I checked the Live 12 manual only.

Ableton/How To/Record MIDI and Audio from external device

  • How to record to Ableton/Track/MIDI and Ableton/Track/Audio simultaneously from an external device

    • My Notes

      • 2025-05-31 Sat
        • With an external keyboard that generates audio, such as an external synthesizer, if you want to record MIDI and audio at the same time into two tracks, one MIDI and one audio, then it's important that you set Ableton Track IO - Monitor set to Off in the MIDI channel.
        • Why? Because if you have Ableton/Track/Record Arm set to on for both tracks, then by default, if you have Ableton Track IO - Monitor set to Auto, then the incoming MIDI notes will trigger an outgoing MIDI note back to the external device, causing a double onset of the external sound, which can sound like a "phaser" effect.
Ableton/Keyshort/Q/What is the "zoom to selection" keyshort in Ableton Live?

    • AI Answer

      • Answer/Official from Live 12 Keyboard Shortcuts
      • Short answer: Z on both macOS and Windows. X zooms back out.
      • Where it applies:

2. First Steps
  • Ableton/Live/UG/02 First Steps/02 Learning About Live

    • 2.2 Learning About Live

      • Live has two built-in learning tools, the Learn View for guided lessons and the Info View for help on whatever is under the mouse. Outside the application there are this manual, videos and interactive web apps.
      • Ableton/Live/UG/02 First Steps/02 Learning About Live/01 Learn View

        • 2.2.1 Learn View

          • The Learn View holds learning modules made of lessons. Each lesson has a video walkthrough, a short text on its key concepts, and links to related lessons.
          • New modules arrive without a Live update. The view needs an internet connection; press Reload after reconnecting.
          • It opens by default on first launch. Close it with the X button and reopen it from the Help menu or with Cmd+Option+7 (Mac) / Ctrl+Alt+7 (Win). It returns to the last page visited until Live quits.
          • Filter lessons by topic, and mark a lesson finished with the Complete Lesson button; finished lessons show a check mark on the home page.
          • The video player can open a picture-in-picture window that stays on top of every application, so you can follow along while working. Its Learn View → button closes it and reopens the Learn View.
      • Ableton/Live/UG/02 First Steps/02 Learning About Live/02 Info View

        • 2.2.2 Info View

3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/01 The Control Bar

    • 3.1 The Control Bar

      • The strip across the top of the window: transport and tempo, scale and MIDI settings, CPU monitoring, and the switch between Session and Arrangement View. See Ableton/Live/UI/Control Bar.
      • It has nine sections:
        • Browser Options: show or hide the browser; the Browser Config Menu expands it to full height and shows the Tuning and Groove Pool sections.
        • Tempo Settings and Metronome: Link, tempo, time signature, metronome options, and Tempo Follower.
        • Scale Settings: the selected clip's scale; changes apply to that clip and to clips created afterwards.
        • Follow and Arrangement Position: Ableton/Live/UI/Control Bar/Switch/Follow and Ableton/Live/UI/Control Bar/Field/Arrangement Position.
        • Transport Controls: Ableton/Live/UI/Control Bar/Button/Play, Ableton/Live/UI/Control Bar/Button/Stop and Ableton/Live/UI/Control Bar/Button/Arrangement Record.
        • Automation and Capture MIDI: MIDI overdub options, Automation Arm, Re-Enable Automation, Capture MIDI, and Session Record.
        • Arrangement Loop Settings: Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop, loop start and length, and the punch-in and punch-out points.
        • MIDI and CPU Settings: Draw Mode, the Computer MIDI Keyboard, Key and MIDI Map Modes, project sample rate, and the CPU meter.
        • View Selector: Ableton/Live/UI/Control Bar/Toggle/View Selector switches between Session and Arrangement View.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/02 The Status Bar

    • 3.2 The Status Bar

      • The Status Bar at the bottom of the window shows error messages and notices of new releases.
      • In the MIDI Note Editor it shows a selected note's position, pitch, velocity and probability. Hovering over an insert marker shows the marker's exact position.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/03 The Browser

    • 3.3 The Browser

      • The Ableton/Browser is where you reach the Core Library, installed Packs, your saved presets and samples, built-in and third-party devices, Sets in Ableton Cloud, files on Push, and folders you add.
      • Show or hide it with the Control Bar toggle or Cmd+Option+5 (Mac) / Ctrl+Alt+5 (Win).
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/04 Sound Similarity

    • 3.4 Sound Similarity

      • Live analyzes sounds to support two features: Similarity Search, which lists Core Library and User Library items that sound like a reference, and Similar Sample Swapping, which replaces samples in Drum Rack, Simpler or Drum Sampler.
      • Similarity Search works on samples up to 60 seconds long, instrument presets and drum presets. Open it with the Show Similar Files icon next to a selected file, the context menu, or Cmd+Shift+F (Mac) / Ctrl+Shift+F (Win). Results run from most to least similar.
      • Analysis runs in the background on new user audio files and can be paused from the Status Bar. Core Library content comes pre-analyzed.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/05 Live Sets

    • 3.5 Live Sets

      • A Live Set (Ableton/File/.als) is the document you work on. It lives in a Live Project, a folder that collects related material.
      • The open Set's Project folder is also reachable from the Current Project label in the browser's Places.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/06 Arrangement and Session

    • 3.6 Arrangement and Session

      • Clips are Live's building blocks: a melody, a drum pattern, a bassline, or a whole song.
      • The Arrangement lays clips out on a linear timeline; the Session is a launching base where each clip has its own play button and can start at any time in any order. See Ableton/Live/Mode/Arrangement and Ableton/Live/Mode/Session.
      • Switch views with Tab or the view controls at the top right. With "Use Tab Key to Navigate" on, use Option+1 / Option+2 (Mac) or Alt+1 / Alt+2 (Win), or the Navigate menu. With two windows, Tab swaps the views between windows.
      • Each view holds its own clips. Switching views changes only the display, not what is playing.
      • The views connect through tracks, so you can improvise with Session clips and record the result into the Arrangement.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/07 Tracks

    • 3.7 Tracks

      • Tracks hold clips and manage signal flow: recording, synthesis, effects and mixing.
      • Session and Arrangement share one set of tracks, shown as columns in the Session and as stacked rows in the Arrangement.
      • A track plays one clip at a time, so clips that alternate go in the same Session column, and clips that play together go across a row, called a scene.
      • A track plays a Session clip or an Arrangement clip, never both, and Session clips win. A track that switched to a Session clip stays off the Arrangement until you press Ableton/Live/UI/Arrangement View/Button/Back to Arrangement, found in the Main track in Session View, at the top right of the scrub area, and on each Arrangement track.
      • Pressing Ableton/Live/UI/Control Bar/Button/Arrangement Record from Session View captures the Session into the Arrangement.
      • Arrangement recordings can produce several takes for comping, and tracks can be linked to edit them together (Ableton/Linked-Track Editing).
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/08 Audio and MIDI

    • 3.8 Audio and MIDI

      • Live handles two kinds of signal. Audio is a series of numbers approximating a waveform; MIDI is a series of commands, like "play a C4 at mezzo piano", closer to a written score.
      • An instrument turns MIDI into audio. Simpler plays one sound chromatically; Impulse assigns a different drum sound to each key.
      • Audio tracks record and play audio clips; MIDI tracks record and play MIDI clips. A clip can't go on the other kind of track. See Ableton/Track/Audio and Ableton/Track/MIDI.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/09 Audio Clips and Samples

    • 3.9 Audio Clips and Samples

      • An audio clip points to a sample (sound file), or a compressed one such as an MP3, and says which part to play and how.
      • Dragging a sample in from the browser creates a clip. The headphones toggle previews a sample when you select it.
      • Clip View settings, opened by double-clicking a clip, change playback in real time without altering the file.
      • Warping changes playback speed independently of pitch to match the song tempo. Auto-Warp lines up most material with the tempo, and extreme settings can change a sound's character.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/10 MIDI Clips and MIDI Files

    • 3.10 MIDI Clips and MIDI Files

      • A MIDI clip holds notes and controller envelopes. Importing a .mid file copies its data into the Set; the file isn't referenced afterward.
      • Edit notes in the Clip View. Besides recording from devices, notes can come from Draw Mode, MIDI Tools, or audio-to-MIDI conversion.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/11 Devices

    • 3.11 Devices

      • Each track can hold a chain of devices. Double-click a track's title bar to open the Device View.
      • Audio effects take and return audio and are the only devices allowed on audio and return tracks. MIDI tracks can also hold MIDI effects and instruments.
      • Add devices by dragging them from the browser onto a track or the Device View, or by selecting one and pressing Enter. VST plug-ins, and Audio Units on macOS, appear under the browser's Plug-Ins label.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/12 Clip and Device View

    • 3.12 Clip and Device View

      • The Ableton/Clip/View sets clip properties such as start and end, looping and scale; in Session View it also has follow actions. Audio clips add warping and audio transformation tools; MIDI clips add pitch and time utilities and MIDI Tools.
      • The Device View lists the devices on the selected track.
      • Stack the two views with the triangle toggles beside their selectors in the bottom-right corner. Cmd+Option+3 / Cmd+Option+4 (Mac) or Ctrl+Alt+3 / Ctrl+Alt+4 (Win) show the Clip View and Device View.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/13 Scale Awareness

    • 3.13 Scale Awareness

      • Scale Mode makes a clip, effect or device scale aware. Turn it on in the Control Bar or the Clip View, then choose a root note and scale. Settings apply to the selected clip, or to new clips when none is selected.
      • In the MIDI Note Editor, Fold to Scale shows only the scale's key tracks, and Highlight Scale tints them purple, the color Live uses for scale awareness everywhere.
      • MIDI Tools and the Pitch and Time Utilities follow the active scale. Arpeggiator, Chord, Pitch, Random and Scale have a Use Current Scale toggle that switches their pitch parameters to scale degrees. Auto Shift's Quantizer and Meld's oscillators and filters can follow the scale too.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/14 The Mixer

    • 3.14 The Mixer

      • A clip's signal passes through the track's device chain from left to right and then into the mixer, which Session and Arrangement share.
      • Device-to-device connections are always stereo; inputs and outputs can be set to mono in the Audio Settings.
      • The mixer has volume, pan and sends. Sends feed return tracks, which hold only effects, so every track can share them.
      • The crossfader works like a DJ mixer's but can fade between any number of tracks, returns included.
      • On a MIDI track, MIDI effects come first, then an instrument, then audio effects. A MIDI track with no instrument outputs plain MIDI and loses its mix and send controls.
      • Show or hide mixer sections from View → Mixer Controls or the Mixer Config Menu at the bottom right.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/15 Presets and Racks

    • 3.15 Presets and Racks

      • Every device can save its settings as a preset. Presets live in the User Library, apart from any Set.
      • Instrument, Drum and Effect Racks save several devices and their settings as one preset. See Ableton/Instrument/Drum Rack and Ableton/File/.adg.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/16 Routing

    • 3.16 Routing

      • The mixer's In/Out section, shown from View → Mixer Controls, is Live's patchbay: a source and a destination chooser for every track.
      • Tracks can send to audio and MIDI interfaces, to other programs, or to a group track that acts as a submixer. They can take input from outside Live or from another track or device, with monitoring controls deciding when the input is heard.
      • External Audio Effect and External Instrument route signals to hardware from within a device chain.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/17 Recording New Clips

    • 3.17 Recording New Clips

      • Arm a track to record its input. Selecting several tracks and arming one arms them all; Cmd-click (Mac) / Ctrl-click (Win) arms several. With Exclusive Arm on, adding an instrument to an empty MIDI track arms it. See Ableton/Track/Record Arm.
      • With Arrangement Record on, each armed track records into the Arrangement, one new clip per take.
      • Session Record records new clips into the selected scene on armed tracks without stopping the music; pressing it again stops recording and launches the clips, cut to the beat by launch quantization.
      • Session recording with overdub and Record Quantization is the usual way to build drum patterns as they loop.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/18 Automation Envelopes

    • 3.18 Automation Envelopes

      • Automation is a control's change over time, stored as a breakpoint envelope you can draw, edit or record. Almost every mixer and device control can be automated, tempo included.
      • With Automation Arm and Arrangement Record on, control changes are recorded into the Arrangement. With Automation Arm on while Session recording, they go into the clip.
      • Moving an automated control while not recording overrides its automation until you press Re-Enable Automation or launch a Session clip that carries automation.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/19 Clip Envelopes

    • 3.19 Clip Envelopes

      • Clips have their own envelopes for automating or modulating device and mixer controls. Audio clips add envelopes for pitch, volume and more; MIDI clips add envelopes for controller data.
      • Unlinked from the clip, an envelope keeps its own loop, so a long fade or a short gesture can run over the clip's material.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/20 MIDI and Key Remote

    • 3.20 MIDI and Key Remote

      • MIDI Map Mode, switched on with the MIDI switch in the Control Bar, assigns most controls to an external MIDI controller: click a control, then move a knob. Mappings take effect when you leave the mode. Session clips can map to a key or key range. See Ableton/Remote Control.
      • Mapped notes and controllers are filtered out before MIDI reaches tracks, so they can't be recorded.
      • Key Map Mode does the same for computer keys, for Session clips, switches and buttons.
      • Push 1, Push 2 and Push 3 have dedicated support.
3. Live Concepts
  • Ableton/Live/UG/03 Live Concepts/21 Saving and Exporting

    • 3.21 Saving and Exporting

      • Saving a Set stores its clips, positions and all settings, but an audio clip loses its sample if the file is moved or deleted. Collect All and Save copies every sample into the Project folder.
      • The Save button in an audio clip's title bar stores default clip settings, such as warp settings, with the sample.
      • File → Export Audio/Video, or Cmd+Shift+R (Mac) / Ctrl+Shift+R (Win), renders the Main output by default. MIDI clips can be exported as MIDI files.
      • Dragging a Session clip to the User Library saves it as a Live Clip (Ableton/File/.alc), which keeps the clip settings and the track's instruments and effects. Useful for drum patterns with their kit, loop variations, and ideas set aside for later. See Ableton/Clip/How To/Save to Library.
