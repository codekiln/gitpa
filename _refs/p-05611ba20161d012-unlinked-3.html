Microfreak/Preset/093 Blind

Page reference

  • Saved export: read from the device's slot 93 over USB on October 25, 2026 with mise run microfreak:download --slot 93. Two consecutive reads returned the same file.
  • The parameter payload matches the MIDI Control Center archives Factory 1.0, Factory 1.1, Factory 2.1, Factory 3.0, Factory 6.0 (Factory 1.0 slot 180, Factory 1.1 slot 180, Factory 2.1 slot 175, Factory 3.0 slot 175, Factory 6.0 slot 416). Comparison used mise run microfreak:compare.
  • Download the slot 93 capture. It is the raw device format (header plus data packets), not an .mbp file; see Microfreak/Preset/093 Blind/Asset/Device-Read-2026-10-25/bin.
  • The saved-parameter inspector preserves the original fields. Oscillator interpretation assumes the documented firmware 5 layout; firmware is not detected from the export.
  • Matrix assignments follow the Freakout live map. Mode, LFO shape, filter type and octave labels follow the MicroFreak Reader definitions.
