Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI

37. Synchronizing with Link, Tempo Follower, and MIDI
  • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link

    • 37.1 Synchronizing via Link

      • Ableton Link keeps beat, tempo and phase in step across apps and devices on a wired or wireless network. Link Audio adds real-time audio streaming between the peers in a Link session, with no extra hardware.
      • Any peer can start and stop on its own and stay in phase, with playback following the global launch quantization. Any peer can change the tempo for everyone, and peers can join or leave without disturbing the others.
      • Link can run alongside Tempo Follower or MIDI sync; the Link session then takes its tempo from that external input.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link/01 Setting up Link and Link Audio

        • 37.1.1 Setting up Link and Link Audio

          • Link and Link Audio have their own Link tab in Ableton/Settings.
          • The Link toggle sits in the Ableton/Live/UI/Control Bar. Set Show Link Toggle to Hide to remove it.
          • The menu beside the toggle switches Link and Link Audio on or off, lists connected Link Audio peers, and opens the settings with Configure Link….
          • Settings on the Link tab:
            • Start Stop Sync — share start and stop between peers that also turn it on.
            • Audio — turns Link Audio on. It works only while the Link toggle is on.
            • Name — the name other peers see.
            • Latency — input latency for incoming audio; the peer list shows how much audio each peer buffers.
            • Sync to Incoming Audio — delays Live's playback by the latency so incoming Link Audio lines up with Live's clips. Only one peer in a session should turn it on.
            • Peers list — each connected Link Audio peer with its status and buffered audio.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link/02 Using Link

        • 37.1.2 Using Link

          • Put the computer on the same network as the other devices, over stable Wi-Fi or a cable, and turn on the Link toggle. Live starts or joins a session, and the toggle shows how many peers are connected.
          • With at least one peer connected and the transport stopped, Ableton/Live/UI/Control Bar/Field/Arrangement Position shows a progress bar for the global launch quantization. After you press play, Live waits for the bar to complete.
          • The first peer sets the starting tempo. After that the last peer to change the tempo wins, and Link tempo changes override tempo automation in the Set.
          • The metronome's recording count-in is unavailable while Link is on.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link/03 Using Link Audio

        • 37.1.3 Using Link Audio

          • Link Audio streams audio between Link peers on the same network, so Live can monitor and record other devices and apps. Both Link and Link Audio must be on for every peer.
          • Each peer appears as an input source. In an audio track, choose the peer in the Input Type chooser and its source track in the Input Channel chooser. Monitoring needs In, or Auto on an armed track; recording needs the track armed.
          • Every track with audio output can be streamed to peers. Live and Push can send and receive; other apps may only send.
37. Synchronizing with Link, Tempo Follower, and MIDI
  • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/02 Synchronizing via Tempo Follower

    • 37.2 Synchronizing via Tempo Follower

      • Tempo Follower listens to an incoming audio signal, works out its tempo in real time, and has Live follow it. It suits cases with no Link or MIDI Clock, or where Live should follow a drummer or a pair of turntables instead of a fixed clock.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/02 Synchronizing via Tempo Follower/01 Setting Up Tempo Follower

        • 37.2.1 Setting Up Tempo Follower

          • In the Tempo Follower section of the Tempo & MIDI Settings, set Input Channel (Ext. In) to the audio interface input carrying the source, such as an overhead microphone or a DJ mixer's record output. Sources with a clear rhythm work best.
          • Turn on Show Tempo Follower Toggle to put a Follow button with the tempo controls in the Ableton/Live/UI/Control Bar. Pressing Follow starts listening; Tempo Follower does not run while the button is hidden.
          • The button grays out when Live cannot reach the chosen input channel.
          • Tempo Follower and External Sync exclude each other. While Tempo Follower runs, Live can still send MIDI clock but cannot receive it.
37. Synchronizing with Link, Tempo Follower, and MIDI
  • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI

    • 37.3 Synchronizing via MIDI

      • Devices without Link can sync over MIDI. Both MIDI methods use a sync host that sends the signal and devices that follow it.
        • MIDI Clock — ticks at a tempo-dependent rate, like a fast metronome, plus song position messages. Live can be host or device.
        • MIDI Timecode — the MIDI form of SMPTE, giving time in seconds and frames. Live reads it as an Arrangement position. It carries no tempo, so tempo changes are not tracked and the tempo must be set by hand. Live can only follow Timecode, not send it.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI/01 Synchronizing External MIDI Devices to Live

        • 37.3.1 Synchronizing External MIDI Devices to Live

          • Live can send MIDI Clock to an external sequencer or drum machine. Set the device up to receive sync, then turn it on as a sync destination in the Tempo & MIDI Settings.
          • The lower LED beside the Control Bar's EXT button flashes while Live sends sync.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI/02 Synchronizing Live to External MIDI Devices

        • 37.3.2 Synchronizing Live to External MIDI Devices

          • To follow an external sequencer, set it up to send sync and enable it as a sync source in the Tempo & MIDI Settings. An EXT button then appears in the Ableton/Live/UI/Control Bar; turn it on, or use Options → External Sync. The upper LED beside EXT flashes when usable sync arrives.
          • Live accepts song position pointers, so it jumps when the host jumps. With Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop on, positions wrap into the loop.

          • 37.3.2.1 MIDI Timecode Options

            • Set per MIDI device by selecting it in the MIDI Ports list of the Tempo & MIDI Settings. Both options apply only when the MIDI Sync Type is MIDI Timecode.
            • MIDI Timecode Rate — the SMPTE frame rate to follow. "SMPTE All" detects the format automatically. The Arrangement's display format is set separately under Options → Time Ruler Format.
            • MIDI Timecode Offset — a SMPTE time that Live treats as the Arrangement's start.
      • Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI/03 Sync Delay

        • 37.3.3 Sync Delay

          • Each MIDI device has a Sync Delay control, shown when the device is selected in the MIDI Ports list, that shifts Live's time base against the sync signal to make up for transmission delay.
          • To set it, have both Live and the other sequencer play a strongly percussive pattern and adjust until the two line up.

38. Computer Audio Resources and Strategies
  • Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load

    • 38.1 Managing the CPU Load

      • Live performs a large number of calculations every second to keep audio flowing. When the processor falls behind, playback and recording get gaps or clicks.
      • What affects CPU performance:
        • Clock speed — instructions per second, in GHz.
        • Architecture — how efficiently the CPU runs instructions and talks to other parts.
        • Cache memory — how fast the CPU fetches data.
        • System bus bandwidth — how fast data moves between components.
        • Temperature — an overheating CPU throttles itself.
      • Live needs a multi-core processor and spreads instruments, effects and I/O across the cores.
      • Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load/01 The CPU Load Meter

        • 38.1.1 The CPU Load Meter

          • The CPU meter in the Ableton/Live/UI/Control Bar compares the time Live takes to compute one audio buffer with the time that buffer takes to play. 50% means computing runs twice as fast as playback; over 100% is possible.
          • The operating system schedules threads, so other applications can cause spikes. The meter counts audio processing only, not work such as drawing Live's interface.
          • The meter's menu, opened from its triangle button or by right-clicking:
            • Average (default) — average load from audio processing.
            • Current — total current, or peak, load. With both on, the menu shows both values and the meter shows average in a lighter shade and current in a darker one.
            • Meter Text Shows — which of the two values appears as a number.
            • Warn on Current CPU Overload — off by default; turns on CPU warnings in the Overload indicator.
      • Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load/02 CPU Load from Multichannel Audio

        • 38.1.2 CPU Load from Multichannel Audio

          • Moving audio between the CPU and the audio hardware is a constant load. Turn off unused inputs and outputs with the Input Config and Output Config buttons in the Audio Settings.
          • Live does not turn them off itself, because some drivers glitch audibly whenever the audio configuration changes.
      • Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load/03 CPU Load from Tracks and Devices

        • 38.1.3 CPU Load from Tracks and Devices

          • Tracks and devices cost CPU only while they process audio. Adding devices while stopped adds little load; an effect with no input is essentially idle, and a reverb or delay stays active until its tail finishes.
          • That lowers average load but not peak load. To stress-test a Set before a show, play a clip on every track with all devices on; if the CPU meter's Current value stays well under 100%, the Set should hold up.
          • The mixer's Performance Impact indicators show each track's share of the load as six rectangles. Turn them on from the Show/Hide Mixer Config menu at the bottom right, or View → Mixer Controls.
          • Freeze a heavy track, or turn off some of its devices, to lower its impact.
      • Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load/04 Track Freeze

        • 38.1.4 Track Freeze

          • Freeze Track renders every Session and Arrangement clip on a track to a sample file, so playback stops recomputing its devices and clip settings. Run it from the Edit menu, a track or clip context menu, or Cmd+Option+Shift+F (Mac) / Ctrl+Alt+Shift+F (Win).
          • Only tracks holding clips can be frozen, so Group Tracks, return tracks and the Main track cannot. Tracks using External Audio Effect or External Instrument freeze in real time.
          • A frozen track's device and clip settings are locked until Unfreeze Track. Bounce Track in Place commits a track to new audio for good, and also works on Group Tracks.
          • Still available on frozen tracks: clip launching, volume, pan and sends, and also:
            • cutting, copying, pasting, duplicating and trimming clips
            • drawing mixer automation and mixer clip envelopes
            • consolidating clips
            • recording Session launches into the Arrangement
            • creating, moving and duplicating scenes
            • dragging frozen MIDI clips onto audio tracks
          • Edits to a frozen track with time-based effects can sound different after unfreezing, because those effects are recomputed then.
          • Frozen Arrangement tracks keep effect tails as crosshatched temporary clips beside the original clips; select the tail along with its clip when moving it. Frozen Session clips hold only two loop cycles.
          • Dragging a frozen clip into a drop area makes a new frozen track with that clip, or only its selected part.
          • Freeze files go in the project's Samples/Processed/Freeze folder, or the Temporary Folder for an unsaved Set. Freezing also lets a slower computer, or one missing a device, play a Set.
38. Computer Audio Resources and Strategies
  • Ableton/Live/UG/38 Computer Audio Resources/02 Managing the Disk Load

    • 38.2 Managing the Disk Load

      • When the disk cannot read or write fast enough, audio drops out and the Overload indicator flashes. Disk traffic grows with the number of audio channels in use; a stereo sample costs more than a mono one.
      • Ways to lower it:
        • Put layered clips, such as stacked vocals, into a Group Track and bounce the group in place to one file.
        • Use RAM Mode on audio clips, so Live reads them from memory instead of disk.
38. Computer Audio Resources and Strategies
  • Ableton/Live/UG/38 Computer Audio Resources/03 The Overload Indicator

    • 38.3 The Overload Indicator

      • The Overload indicator in the Ableton/Live/UI/Control Bar shows "Disk" when the disk falls behind and, once CPU warnings are on, "CPU" when the processor is overloaded.
      • CPU warnings are off by default. Turn them on with Warn on Current CPU Overload in the CPU meter's menu or CPU Overload Indicator in the indicator's context menu; the two options share one state.
      • Both kinds of overload can cause dropouts or crackles while playing or recording.

      • That lowers average load but not peak load. To stress-test a Set before a show, play a clip on every track with all devices on; if the CPU meter's Current value stays well under 100%, the Set should hold up.
      • The mixer's Performance Impact indicators show each track's share of the load as six rectangles. Turn them on from the Show/Hide Mixer Config menu at the bottom right, or View → Mixer Controls.
      • Freeze a heavy track, or turn off some of its devices, to lower its impact.
38.1 Managing the CPU Load
  • Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load/04 Track Freeze

    • 38.1.4 Track Freeze

      • Freeze Track renders every Session and Arrangement clip on a track to a sample file, so playback stops recomputing its devices and clip settings. Run it from the Edit menu, a track or clip context menu, or Cmd+Option+Shift+F (Mac) / Ctrl+Alt+Shift+F (Win).
      • Only tracks holding clips can be frozen, so Group Tracks, return tracks and the Main track cannot. Tracks using External Audio Effect or External Instrument freeze in real time.
      • A frozen track's device and clip settings are locked until Unfreeze Track. Bounce Track in Place commits a track to new audio for good, and also works on Group Tracks.
      • Still available on frozen tracks: clip launching, volume, pan and sends, and also:
        • cutting, copying, pasting, duplicating and trimming clips
        • drawing mixer automation and mixer clip envelopes
        • consolidating clips
        • recording Session launches into the Arrangement
        • creating, moving and duplicating scenes
        • dragging frozen MIDI clips onto audio tracks
      • Edits to a frozen track with time-based effects can sound different after unfreezing, because those effects are recomputed then.
      • Frozen Arrangement tracks keep effect tails as crosshatched temporary clips beside the original clips; select the tail along with its clip when moving it. Frozen Session clips hold only two loop cycles.
      • Dragging a frozen clip into a drop area makes a new frozen track with that clip, or only its selected part.
      • Freeze files go in the project's Samples/Processed/Freeze folder, or the Temporary Folder for an unsaved Set. Freezing also lets a slower computer, or one missing a device, play a Set.

39. Audio Fact Sheet
  • Ableton/Live/UG/39 Audio Fact Sheet/01 Testing and Methodology

    • 39.1 Testing and Methodology

      • Every Live release runs through automated tests that cover the program's functions, and Ableton adds tests as it adds features. A release ships only when it passes all of them.
39. Audio Fact Sheet
  • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations

    • 39.2 Neutral Operations

      • A neutral operation leaves the audio unchanged. Recorded audio stays identical to what the A/D converter delivered, imported files stay identical to the files on disk, and an export is at least as good as what played back.
      • Neutral operations usually happen alongside non-neutral ones. Any neutral step that follows an effect or a gain change still carries that change.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/01 Undithered Rendering

        • 39.2.1 Undithered Rendering

          • Export Audio/Video is neutral when the file's sample rate matches the audio hardware rate in Live's Settings and no non-neutral operation was applied.
          • Ableton's phase-cancellation tests rendered white noise, sine waves and sine sweeps at 16, 24 and 32 bits:
            • Same or higher bit depth than the original: complete cancellation.
            • Lower bit depth: the smallest distortion a 32-bit system allows.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/02 Matching Sample Rate-No Transposition

        • 39.2.2 Matching Sample Rate/No Transposition

          • An unstretched file plays back neutrally when its sample rate matches Live's Settings and it is not transposed. This covers audio inside Live only, before it reaches the audio hardware.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/03 Unstretched Beats-Tones-Texture-Re-Pitch Warping

        • 39.2.3 Unstretched Beats/Tones/Texture/Re-Pitch Warping

          • A clip at the Set's tempo plays unstretched. In Beats, Tones, Texture or Re-Pitch Warp modes that playback is neutral; Complex and Complex Pro are not.
          • Tempo changes stretch only while they last. Tracks recorded at 120 BPM play back neutrally again once the tempo returns to 120 BPM.
          • Arrangement tempo automation in Beats mode with transient preservation can cause artifacts. Preserving 16ths or using Re-Pitch avoids them.
          • Grooves move Warp Markers, so a clip with a groove is never neutral, even at its original tempo.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/04 Summing at Single Mix Points

        • 39.2.4 Summing at Single Mix Points

          • Live sums signals in 64-bit double precision at every mix point: clip and return track inputs, the Main track and Racks. Mixing at a single point is therefore neutral.
          • Internal processing stays 32-bit, so a signal mixed across several summing points can lose a very small amount of quality.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/05 Recording External Signals (Bit Depth at Least A-D Converter)

        • 39.2.5 Recording External Signals (Bit Depth >/= A/D Converter)

          • Recording an external signal is neutral when the bit depth in Live's Settings is equal to or higher than the A/D converter's. Neutral here means identical to what the converter delivered.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/06 Recording Internal Sources at 32 Bit

        • 39.2.6 Recording Internal Sources at 32 Bit

          • Recording through internal routing is neutral at 32 bits. Use 32 bits for plug-in instruments and effected signals.
          • A source that is already at a lower bit depth records neutrally at that depth; recording a 16-bit file at 32 bits adds no quality.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/07 Freezing Tracks

        • 39.2.7 Freezing Tracks

          • Freeze writes 32-bit files, so frozen audio is no worse than what played before freezing. Some cases still change the result:
            • Frozen Session View clips are two loop cycles long, so longer tails get cut off. Arrangement View freezes keep tails past the clip end.
            • Frozen reverb and delay tails stop abruptly when playback stops, because they are rendered audio.
            • Frozen Arrangement clips include their automation. Frozen Session clips keep the parameter values found at the Arrangement's 1.1.1 position.
            • Frozen clips always play with Warp on in Beats mode.
            • Random device parameters, such as Beat Repeat's Chance, stop being random after freezing.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/08 Bypassed Effects

        • 39.2.8 Bypassed Effects

          • A bypassed effect is taken out of the signal flow, for Live's devices and for VST and AU plug-ins alike, so its output equals its input.
          • Devices with built-in delay, such as Compressor's Lookahead, keep that delay while bypassed so delay compensation stays correct.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/09 Routing

        • 39.2.9 Routing

          • Routing a signal is neutral: the destination receives the same signal the source sends.
          • Tapping a signal partway through a chain, such as before a track's effects or from a single Impulse sample slot, gives a different signal than the end of that chain.
      • Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/10 Splitting Clips

        • 39.2.10 Splitting Clips

          • Splitting a neutral clip keeps it neutral. A split changes only the playback position in the sample, and playback across the split has no gap and is sample-accurate.
          • Ableton tested unwarped clips and warped-but-unstretched clips, with loop on and off, against unsplit renders.
39. Audio Fact Sheet
  • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations

    • 39.3 Non-Neutral Operations

      • A non-neutral operation always changes the signal in some way. Imported files then differ from the files on disk, and exports differ from what played in real time.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/01 Playback in Complex and Complex Pro Mode

        • 39.3.1 Playback in Complex and Complex Pro Mode

          • Complex and Complex Pro use a different technology from the other Warp modes. They can sound better on mixed material but are never neutral, even at the original tempo, and they use more CPU.
          • Ableton recommends them only when the other Warp modes fall short.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/02 Sample Rate Conversion-Transposition

        • 39.3.2 Sample Rate Conversion/Transposition

          • Playing a file whose sample rate differs from Live's Settings degrades it. Transposition is a form of sample-rate conversion and is also non-neutral.
          • Convert sample rates offline before importing rather than mixing rates within one Set.
          • Exporting at a different rate from the project's also converts. Live uses the SoX Resampler library for this, which keeps distortion very low.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/03 Volume Automation

        • 39.3.3 Volume Automation

          • Volume automation changes gain, so it is non-neutral. Live updates volume automation for every sample, which keeps distortion very low.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/04 Dithering

        • 39.3.4 Dithering

          • Dither when rendering to a lower bit depth. Dither is low-level noise, so it is non-neutral.
          • Any gain change in Live produces 32-bit audio. Apply dither only once; unless you master in Live, render at 32 bits and skip dither.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/05 Recording External Signals (Bit Depth Below A-D Converter)

        • 39.3.5 Recording External Signals (Bit Depth < A/D Converter)

          • Recording at a bit depth lower than the A/D converter's loses quality. Ableton does not recommend it.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/06 Recording Internal Sources Below 32 Bit

        • 39.3.6 Recording Internal Sources Below 32 Bit

          • Internal recordings below 32 bits lose quality. A source already at that lower depth, with no effects, still records neutrally.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/07 Consolidate

        • 39.3.7 Consolidate

          • Consolidating Arrangement clips writes new, normalized files with clip volume adjusted to sound the same. Normalizing is a gain change.
          • The new files use the sample rate and bit depth from Live's Settings, which can differ from the originals.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/08 Clip Fades

        • 39.3.8 Clip Fades

          • Create Fades on Clip Edges, in the Record, Warp & Launch Settings, adds fades of up to 4 ms at clip edges to prevent clicks. Session clips have a Clip Fade button for the same purpose.
          • These fades, and Arrangement clip fades and crossfades, are all non-neutral.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/09 Panning

        • 39.3.9 Panning

          • Live pans with constant power and sinusoidal gain curves: 0 dB at center, +3 dB fully left or right.
          • Narrowing stereo width first, with Utility's Width control, reduces the level jump from extreme panning.
      • Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/10 Grooves

        • 39.3.10 Grooves

          • A warped clip at the Set's tempo normally plays neutrally, but once a groove is applied playback is non-neutral at every tempo.
39. Audio Fact Sheet
  • Ableton/Live/UG/39 Audio Fact Sheet/04 Tips for Achieving Optimal Sound Quality in Live

    • 39.4 Tips for Achieving Optimal Sound Quality in Live

      • Practices for the highest audio quality:
        • Pick the project's sample rate before starting and keep it.
        • Record with good hardware at the highest sample rate and bit depth your interface and computer support.
        • Keep all samples at one sample rate; convert others offline first.
        • Turn off Warp and Fade for every audio clip in Clip View.
        • Leave clip Transpose and Detune alone.
        • Render at 32 bits.
      • These settings give up stretching and synchronization.

    • 39.5 Conclusion

      • The fact sheet covers the operations that have caused the most confusion. Its lists of neutral and non-neutral operations are not complete.
