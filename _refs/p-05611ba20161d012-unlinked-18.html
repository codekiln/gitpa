Unlinked references: Microfreak

Music/Scale/Blues
  • The MicroFreak manual lists its "Blues" setting as nine notes: C D E♭ F G♭ G A♭ A B♭. That collection is the hexatonic blues scale plus 2, ♭6 and 6, larger than any standard blues scale. The same manual's introduction to scales says blues scales use six notes. See Microfreak/UG/15 Using Scales/01 Scale Settings and Microfreak/UG/15 Using Scales.
Music/Scale/Dorian
  • The MicroFreak manual spells its "Dorian" and "Minor" settings almost identically; the "Minor" spelling is this scale with an added B natural. See Microfreak/UG/15 Using Scales/01 Scale Settings.
Music/Scale/Dorian/Bebop
  • Sources disagree on which note to add. The major-seventh form, C D E♭ F G A B♭ B, matches the MicroFreak manual's spelling of its "Minor" setting in Microfreak/UG/15 Using Scales/01 Scale Settings.
Music/Scale/Major
  • Its association with brightness or happiness is learned. The MicroFreak manual's chapter on scales says as much in Microfreak/UG/15 Using Scales.
Music/Scale/Minor/Harmonic
  • The MicroFreak manual lists its "Harmonic Minor" setting as C D E F G A♭ B. With E natural, that collection is harmonic major, Person/Nikolai Rimsky-Korsakov's name for a major scale with a lowered sixth. The manual page is Microfreak/UG/15 Using Scales/01 Scale Settings; which collection the firmware plays is not documented there.
Music/Scale/Minor/Natural
  • The MicroFreak's "Minor" setting is listed in its manual as C D E♭ F G A B♭ B, which lacks A♭, the note that separates natural minor from Dorian, and adds B natural. See Microfreak/UG/15 Using Scales/01 Scale Settings and Music/Scale/Dorian/Bebop. The Launchpad's "Natural Minor" setting carries this scale's name; its manual lists no pitches.
Music/Scale/Pentatonic/Major
  • Also called the Music/Anhemitonic pentatonic, gong mode in Chinese theory, and the MicroFreak's "Pentatonic" setting. On C: C D E G A. Steps in semitones: 2 2 3 2 3.
