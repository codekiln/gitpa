NotesSaved export and provenance
  • Download the slot 29 capture. It is the raw device format (header plus data packets), not an .mbp file; see Microfreak/Preset/029 Number Station/Asset/Device-Read-2026-10-25/bin.
NotesOscillator
  • Model: Speech. Microfreak/UG/06 Dig Osc/03 Types/11 Speech
NotesOscillator
  • Type: 0.607. Timbre: 0.499. Word: 0.633.
NotesOscillator
  • Keyboard octave: +1. Glide: 0.000.
NotesFilter
  • Low-pass filter. Saved cutoff: 0.932; resonance: 0.201. Microfreak/UG/07 Filter/01 Modifying Sound/01 Low Pass Filter
NotesEnvelopes
  • Main envelope: attack 0.000, decay/release 0.244, sustain 0.999. Amp Mod is on, so the main envelope controls loudness. Microfreak/UG/09 Envelope Gen/03 Envelope Stages
NotesEnvelopes
  • Cycling Envelope mode: Run. Stored RiseLvl 0.110, RiseSlp 0.500, FallLvl 0.111, FallSlp 0.500, Hold 0.000, Amount 0.495. Microfreak/UG/09 Envelope Gen/06 Cycling Envelope
NotesLFO
  • Sample-and-Hold Filtered, clock sync off; stored normalized rate: 0.630. Microfreak/UG/08 LFO/01 LFO Shape · Microfreak/UG/08 LFO/02 LFO Rate
NotesModulation matrix
  • Amounts use the signed normalized range −1…+1. Microfreak/UG/05 Connections/02 Matrix and Encoder/01 Sources and Destinations
NotesModulation matrix
  • LFO → Assign 1 → Word: +0.500.
NotesModulation matrix
  • PRESSURE → Assign 2 → Filter Cutoff: −0.300.
NotesModulation matrix
  • PRESSURE → Assign 3 → Filter Resonance: +0.585.
NotesVoice and keyboard
  • Paraphonic mode: off.
NotesPerformance and session context
  • Hold a note to let the filtered random LFO move the Speech Word selector. The oscillator keeps changing syllables while pitch stays under the keyboard; the Speech guide explains how Type chooses a library and Word scans within it. Microfreak/UG/06 Dig Osc/03 Types/11 Speech
NotesPerformance and session context
  • The saved pressure routes lower the low-pass cutoff and raise resonance together, emphasizing a narrower, more muffled voice as expression increases. The PRESSURE source follows the global pressure-or-velocity setting, which the preset export cannot establish. Microfreak/UG/05 Connections/02 Matrix and Encoder/01 Sources and Destinations
