9.5 Pattern Settings
  • Launchpad/UG/09 Sequencer/05 Pattern Settings/01 Sync Rate

    • 9.5.1 Pattern Sync Rate

      • Eight peach pads set how long each step lasts relative to the current tempo: 1/4, 1/4T, 1/8, 1/8T, 1/16, 1/16T, 1/32, or 1/32T. T denotes a triplet.
      • The default is 1/16, one sixteenth note per step. Faster rates give finer step resolution but shorten the Pattern’s total duration. Slower rates make longer Patterns with less timing detail.
9.5 Pattern Settings
  • Launchpad/UG/09 Sequencer/05 Pattern Settings/02 Direction

    • 9.5.2 Pattern Playback Direction

      • Four pink pads select playback order from left to right:
        • Forward: Play from the start step to the end step.
        • Backward: Play from the end step to the start step.
        • Ping-Pong: Alternate forward and backward. Both endpoint steps play twice, so the Pattern cycle doubles in length.
        • Random: Choose each step anew during playback. A step may repeat any number of times in one cycle, but the cycle keeps its length when chained to other Patterns.
      • Changes made during playback take effect at the end of the current Pattern cycle.
9.5 Pattern Settings
  • Launchpad/UG/09 Sequencer/05 Pattern Settings/03 Start End

    • 9.5.3 Pattern start and end points

      • In Pattern Settings, press a step to set the Pattern’s end point; the selected end step lights peach.
      • Hold Shift to display the start point in peach, then press a step while Shift is held to move the start point.
      • Steps containing notes outside the selected range are dim red. Empty steps outside the range stay unlit.

9.6 Velocity
  • Launchpad/UG/09 Sequencer/06 Velocity/01 Step Velocity

    • 9.6.1 Step Velocity edit

      • Press Velocity to see and edit the velocity of each step. Select a step in the top half of the grid; its velocity appears on the two-row slider at the top of the Play Area.
      • Press a slider pad to set the selected step’s velocity from 1 (minimum) to 16 (maximum). Manual edits set every note on a multi-note step to the same velocity.
      • Velocity view
9.6 Velocity
  • Launchpad/UG/09 Sequencer/06 Velocity/02 Live Record

    • 9.6.2 Live Recording with Velocity

      • Live recording can put notes with different velocities on one step. Bright pads show the lowest velocity; dim pads show the range up to the highest recorded velocity.

9.7 Probability
  • Launchpad/UG/09 Sequencer/07 Probability/01 Edit

    • 9.7.1 Editing Step Probability

      • Press Probability, then select a step in the top half of the grid. The top row of the Play Area shows the selected step’s probability on an eight-pad slider.
      • The pads, from left to right, set the chance of a note playing to 13%, 25%, 38%, 50%, 63%, 75%, 88%, or 100%.
      • Every note on a step shares one probability setting, but each note is evaluated independently. At 50%, a two-note step may play both notes, one note, or neither.
      • Assigned or recorded notes default to 100%. Clearing a step, Pattern, or Project also resets its probability to 100%.
      • Probability view
9.7 Probability
  • Launchpad/UG/09 Sequencer/07 Probability/02 Print

    • 9.7.2 Printing Probability

      • Launchpad/UG/09 Sequencer/11 Print to Clip resolves the probability of each step once when it transfers the Pattern to Ableton Live. Print the same Pattern repeatedly to capture repeatable variations in separate clips.

9.8 Mutation
  • Launchpad/UG/09 Sequencer/08 Mutation/01 Edit

    • 9.8.1 Editing Step Mutation

      • Press Mutation and select a step in the top half of the grid. The top row of the Play Area shows an eight-pad Mutation slider for that step.
      • The leftmost value means no Mutation; the rightmost is the maximum. Newly recorded or assigned steps begin with no Mutation (one pad lit).
      • Mutation view
9.8 Mutation
  • Launchpad/UG/09 Sequencer/08 Mutation/02 Print

    • 9.8.2 Printing Mutation

      • Launchpad/UG/09 Sequencer/11 Print to Clip resolves each step’s Mutation once as it transfers the Pattern to Ableton Live. Print repeatedly to capture several repeatable variations.
      • Combine Mutation with Launchpad/UG/09 Sequencer/07 Probability to make evolving Patterns, then print the results as clips.

9.9 Micro Steps
  • Launchpad/UG/09 Sequencer/09 Micro Steps/01 Edit

    • 9.9.1 Editing Micro Steps

      • Press Micro Steps and select a step in the top half of the grid. The six leftmost pads of the Play Area’s top row represent that step’s Micro Steps.
      • Hold a note in the Play Area and press a Micro Step to assign it. To remove a note, hold its Micro Step and press the assigned red note in the Play Area.
      • Micro Step editing view
9.9 Micro Steps
  • Launchpad/UG/09 Sequencer/09 Micro Steps/02 Clear

    • 9.9.2 Clearing micro steps

      • Hold Clear and press a Micro Step to erase its notes. To remove one note, hold the Micro Step and press the assigned red note in the Play Area.
9.9 Micro Steps
  • Launchpad/UG/09 Sequencer/09 Micro Steps/03 Duplicate

    • 9.9.3 Duplicating steps

      • Hold Duplicate and press a source Micro Step, then press a destination Micro Step while still holding Duplicate.
      • The paste does not occur if it would raise the total notes on the whole step above eight.

9.10 Tempo and Swing
  • Launchpad/UG/09 Sequencer/10 Tempo and Swing/01 Edit

    • 9.10.1 Editing Tempo and Swing

      • Hold Shift and press Device to open Tempo view (blue and white). The displayed number is the current BPM.
      • Hold Shift and press Stop Clip to open Swing view (orange and white). A value above 50 delays off-beat notes; a value below 50 moves them earlier.
      • Use the Up and Down arrows to adjust either value. Hold an arrow to cycle quickly.
      • Tempo view
      • Swing view

9.12 Projects
  • Launchpad/UG/09 Sequencer/12 Projects/01 Save

    • 9.12.1 Saving your Sequencer Project

      • From Steps, Projects, or Patterns View, hold Shift and press Projects to start saving. Save pulses green. Press Projects again to save to the active slot; Save flashes briefly while the device writes, and controls are unavailable during that moment.
      • To cancel saving, press a button other than Shift, Projects, or Setup.
      • To save to a different slot in Projects View, hold Shift and press Projects. Save pulses white. You may choose one of eight Project colors with the track-select buttons, then press the desired Project slot. Save and the slot flash to confirm.
      • A saved Project also includes Note and Chord mode settings and every Custom Mode master MIDI channel.
9.12 Projects
  • Launchpad/UG/09 Sequencer/12 Projects/02 Backup

    • 9.12.2 Backing up your Projects

      • Novation Components can back up Projects online. It is available in a Web MIDI browser or as a standalone download from the Novation Customer Portal.

9.13 Sequencer Settings
  • Launchpad/UG/09 Sequencer/13 Settings/01 Access

    • 9.13.1 Accessing Sequencer Settings

      • Hold Shift and press Sequencer to open Sequencer Settings.
      • Sequencer Settings view
9.13 Sequencer Settings
  • Launchpad/UG/09 Sequencer/13 Settings/02 Track Types

    • 9.13.2 Track Types

      • Use the three pads at the top right to choose Drum, Scale, or Chromatic. Select the track to change with its track-select button.
      • The top-left 4 × 2 pads preview the left side of the chosen track’s Play Area layout.
9.13 Sequencer Settings
  • Launchpad/UG/09 Sequencer/13 Settings/03 Root and Scale

    • 9.13.3 Root Select/Scale Viewer

      • The piano-layout viewer shows scale notes in blue, the root in purple, and out-of-scale notes in dim white.
      • Press a pad in the viewer to change the root. The root selection applies in Note, Chord, and Sequencer modes.
9.13 Sequencer Settings
  • Launchpad/UG/09 Sequencer/13 Settings/04 Select Scale

    • 9.13.4 Selecting the Scale

      • Press one of the 16 scale pads. The selected scale lights bright white; the others are dim blue. The choice applies in Note, Chord, and Sequencer modes.
      • Available scales:
        • Natural Minor; Natural Major; Dorian; Phrygian; Mixolydian; Melodic Minor; Harmonic Minor; Bebop Dorian.
        • Blues; Minor Pentatonic; Hungarian Minor; Ukrainian Dorian; Marva; Todi; Whole Tone; Hirajoshi.
9.13 Sequencer Settings
  • Launchpad/UG/09 Sequencer/13 Settings/05 MIDI Channel

    • 9.13.5 Setting MIDI Channel

      • Each track can transmit on any MIDI channel from 1 to 16. Assign different channels to address separate Ableton Live instruments or external hardware.

10. Setup
  • Launchpad/UG/10 Setup/01 Setup Menu

    • 10.1 Setup Menu

      • Hold Setup to open the menu. The upper rows spell the active page name. The five leftmost Track Select buttons choose LED, Velocity, Aftertouch, MIDI, or Fader settings.
10. Setup
  • Launchpad/UG/10 Setup/02 LED Settings

    • 10.2 LED Settings

      • Press the first Track Select button. Choose among eight brightness levels; the bright white pad marks the active level.
      • Vegas Mode starts after five minutes without activity. Its toggle is green when enabled and red when disabled.
      • 10.2.A — LED Settings view
10. Setup
  • Launchpad/UG/10 Setup/03 Velocity Settings

    • 10.3 Velocity Settings

      • Press the second Track Select button for VEL settings. Toggle pad velocity globally: bright green is enabled and dim red is disabled.
      • Choose Low, Medium, or High velocity response. Low needs more force for a high value; High needs less. The selected curve glows bright orange; the others are dim white.
      • 10.3.A — Velocity Settings view
10. Setup
  • Launchpad/UG/10 Setup/04 Aftertouch Settings

    • 10.4 Aftertouch Settings

      • Press the third Track Select button for AFT settings. Choose disabled pressure, Polyphonic Aftertouch, or Channel Pressure. The active choice is bright.
      • Channel Pressure sends one value for all pads, using the greatest pressure on the grid. Polyphonic Aftertouch sends a separate value for each pad. The guide recommends Channel Pressure with Ableton Live, which does not support polyphonic aftertouch in the version it describes.
      • Set the Aftertouch Threshold to Off, Low, or High. Off sends pressure from the start of a press; Low and High require increasing pressure before messages begin. This helps avoid engaging an assigned effect as soon as a pad is touched.
      • 10.4.A — Aftertouch Settings view
10. Setup
  • Launchpad/UG/10 Setup/05 MIDI Settings

    • 10.5 MIDI Settings

      • Press the fourth Track Select button. Receive Clock controls whether incoming MIDI clock is followed; Transmit Clock controls whether Launchpad Pro sends clock. Both default to On.
      • Set the second MIDI output to Out 2 to duplicate Out 1, or Thru to forward messages arriving at MIDI In.
      • 10.5.A — MIDI Settings view
10. Setup
  • Launchpad/UG/10 Setup/06 Fader Settings

    • 10.6 Fader Settings

      • Press the fifth Track Select button for FAD settings. Fader velocity can be enabled separately from the global pad velocity setting. The toggle is bright green when enabled and dim red when disabled.
      • 10.6.A — Fader Settings view
10. Setup
  • Launchpad/UG/10 Setup/07 Live and Programmer Mode

    • 10.7 Live and Programmer Mode

      • Live Mode gives access to Session, Note, Chord, Custom, and Sequencer modes. It is the default at power-on.
      • Programmer Mode lets external MIDI software control the surface. Each pad and button sends and responds to its assigned MIDI message; the other device modes are unavailable while Programmer Mode is active.
      • Hold Setup and press the green Scene Launch button for Live Mode or the orange Scene Launch button for Programmer Mode. Release Setup to enter the selected mode.
      • The Programmer’s Reference Guide describes the MIDI messages that light pads and buttons.
      • 10.7.A — Live and Programmer Mode selection
10. Setup
  • Launchpad/UG/10 Setup/08 Bootloader Menu

    • 10.8 Bootloader Menu

      • Hold Setup while plugging in Launchpad Pro to open the bootloader menu.
      • The eight-level brightness slider can lower power use when a USB host cannot supply enough power for a full-brightness startup. The bright white pad marks the active level.
      • Bootloader Version and App Version show installed versions. Boot Up exits the menu and starts the controller normally.
      • Set a different Device ID on each Launchpad Pro when using several with Live. Each unit then has an independent Session View outline.
      • MSD Mode controls whether the device appears as a mass storage drive. It is on by default; the bright pad means enabled and the dim pad means disabled. The LAUNCHPAD drive contains a link to the Easy Start Tool.
      • 10.8.A — Bootloader menu
