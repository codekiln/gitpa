Ableton/Live/UG/03 Live Concepts/01 The Control Bar
3.1 The Control Bar
  • The strip across the top of the window: transport and tempo, scale and MIDI settings, CPU monitoring, and the switch between Session and Arrangement View. See Ableton/Live/UI/Control Bar.
3.1 The Control BarIt has nine sections:
  • Follow and Arrangement Position: Ableton/Live/UI/Control Bar/Switch/Follow and Ableton/Live/UI/Control Bar/Field/Arrangement Position.
3.1 The Control BarIt has nine sections:
  • Transport Controls: Ableton/Live/UI/Control Bar/Button/Play, Ableton/Live/UI/Control Bar/Button/Stop and Ableton/Live/UI/Control Bar/Button/Arrangement Record.
3.1 The Control BarIt has nine sections:
  • Arrangement Loop Settings: Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop, loop start and length, and the punch-in and punch-out points.
3.1 The Control BarIt has nine sections:
  • View Selector: Ableton/Live/UI/Control Bar/Toggle/View Selector switches between Session and Arrangement View.
Ableton/Live/UG/03 Live Concepts/07 Tracks
3.7 Tracks
  • A track plays a Session clip or an Arrangement clip, never both, and Session clips win. A track that switched to a Session clip stays off the Arrangement until you press Ableton/Live/UI/Arrangement View/Button/Back to Arrangement, found in the Main track in Session View, at the top right of the scrub area, and on each Arrangement track.
3.7 Tracks
  • Pressing Ableton/Live/UI/Control Bar/Button/Arrangement Record from Session View captures the Session into the Arrangement.
Ableton/Live/UG/06 Arrangement View/01 Layout
6.1 Layout
  • Garden pages for the view and its controls: Ableton/Live/UI/Arrangement View.
6.1 LayoutUpper area:
  • Ableton/Live/UI/Arrangement View/Scrub Area: click to play from that point; hold the mouse button to loop that spot by the global launch quantization.
6.1 LayoutUpper area:
  • Ableton/Live/UI/Arrangement View/Scrub Area/Marker/Locators mark launchable sections. Ableton/Live/UI/Arrangement View/Button/Set Locator adds them during playback or recording and becomes Delete Locator when one is selected; Ableton/Live/UI/Arrangement View/Button/Previous Locator and Ableton/Live/UI/Arrangement View/Button/Next Locator jump between them, quantized.
6.1 LayoutUpper area:
  • Ableton/Live/UI/Arrangement View/Toggle/Automation Mode shows or hides automation lanes.
6.1 LayoutUpper area:
  • Ableton/Live/UI/Arrangement View/Toggle/Lock Envelopes ties envelopes to the song position instead of the clips, so clips move without their automation.
6.1 LayoutTracks and lower area:
  • Ableton/Live/UI/Arrangement View/Slider/Waveform Vertical Zoom Level enlarges waveforms in all audio tracks without changing clip gain.
6.1 LayoutTracks and lower area:
  • Ableton/Live/UI/Arrangement View/Time Ruler shows minutes-seconds-milliseconds; drag it to scroll.
Ableton/Live/UG/06 Arrangement View/02 Navigation and Zooming
6.2 Navigation and Zooming
  • Ableton/Live/UI/Control Bar/Switch/Follow, or Options → Follow (Ableton/Menu/Options/Follow), scrolls with the song position. It pauses when you edit, scroll sideways or click the beat-time ruler, and resumes on stop, restart, or a click in a scrub area.
Ableton/Live/UG/06 Arrangement View/03 Transport and Playback
6.3 Transport and Playback
  • Ableton/Live/UI/Control Bar/Button/Play and Ableton/Live/UI/Control Bar/Button/Stop, or the space bar, start and stop playback. Keys and MIDI can be mapped to the transport.
6.3 Transport and Playback
  • Playback starts from the flashing blue Ableton/Live/UI/Arrangement View/Marker/Insert Marker, at the Arrangement start by default. Click in a track to move it; double-click Stop, or press Home (Win) / Fn+Left (Mac), to send it back to the start.
6.3 Transport and Playback
  • Ableton/Live/UI/Control Bar/Field/Arrangement Position shows the play position in bars-beats-sixteenths; drag, type and Enter, or use the arrow keys to change it, which also moves the insert marker.
6.3 Transport and Playback
  • With Permanent Scrub Areas on (the default, in Display & Input Settings), click anywhere in the Ableton/Live/UI/Arrangement View/Scrub Area to play from there; jumps follow Ableton/Live/UI/Control Bar/Menu/Quantization, and holding the button repeats that portion. With it off, Shift-click the scrub area or beat-time ruler.
Ableton/Live/UG/06 Arrangement View/04 Launching the Arrangement with Locators
6.4 Launching the Arrangement with Locators
  • Locators in the scrub area (Ableton/Live/UI/Arrangement View/Scrub Area/Marker/Locator) are launch points in the Arrangement.
6.4 Launching the Arrangement with Locators
  • Ableton/Live/UI/Arrangement View/Button/Set Locator adds one in real time, quantized to the global launch quantization; with the transport stopped it adds one at the insert marker or the start of the time selection. Add Locator in the scrub area's context menu or the Create menu also works. With a locator selected, the button deletes it.
6.4 Launching the Arrangement with Locators
  • Click a locator, or use Ableton/Live/UI/Arrangement View/Button/Previous Locator and Ableton/Live/UI/Arrangement View/Button/Next Locator, to jump; past the first or last locator they go to the Arrangement's start or end. Locators can be MIDI or key mapped; with the transport stopped, double-click one to play from it.
Ableton/Live/UG/06 Arrangement View/05 Time Signature Changes
6.5 Time Signature Changes
  • Ableton/Live/UI/Arrangement View/Marker/Time Signature Markers change the meter anywhere. Insert one at the insert marker with Create → Insert Time Signature Change or the scrub area's context menu.
6.5 Time Signature Changes
  • Typing in the Control Bar's Ableton/Live/UI/Control Bar/Field/Time Signature fields changes the meter at the play position, stopped or playing. An LED in the fields' corner means the Arrangement has meter changes.
Ableton/Live/UG/06 Arrangement View/06 The Arrangement Loop
6.6 The Arrangement Loop
  • Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop repeats part of the Arrangement. With nothing selected, the Ableton/Live/UI/Arrangement View/Marker/Loop Brace spans the whole Arrangement.
6.6 The Arrangement Loop
  • Ableton/Live/UI/Control Bar/Field/Loop Start and Ableton/Live/UI/Control Bar/Field/Loop Length set it numerically.
Ableton/Live/UG/07 Session View/05 Recording Sessions into the Arrangement
7.5 Recording Sessions into the Arrangement
  • With Ableton/Live/UI/Control Bar/Button/Arrangement Record on, Live logs Session playing into the Arrangement: launched clips, changes to their properties, mixer and device automation, and tempo and meter changes from launched scenes. Press it again or stop to finish.
7.5 Recording Sessions into the Arrangement
  • A track plays either its Session clip or its Arrangement, not both. Launching a Session clip, or pressing a Clip Stop button, takes the track off the Arrangement until you press Ableton/Live/UI/Arrangement View/Button/Back to Arrangement, which lights up while what you hear differs from the Arrangement.
Ableton/Live/UG/09 Audio Clips Tempo and Warping/02 Warping/03 Warp Markers
9.2.3 Warp Markers
  • Ableton/Live/UI/Control Bar/Switch/Follow scrolls the editor during playback; it pauses on edits.
Ableton/Live/UG/10 Editing MIDI/02 Zooming and Navigating in the MIDI Note Editor/02 Playback Options
10.2.2 Playback Options
  • Ableton/Live/UI/Control Bar/Switch/Follow scrolls the editor with playback; an edit pauses it until you press Follow again, restart playback, or click a scrub area after stopping.
Ableton/Live/UG/16 Launching Clips/04 Clip Launch Quantization
16.4 Clip Launch Quantization
  • Clip Quantization corrects the launch timing of a clip. None turns it off; Global follows the Control Bar's Ableton/Live/UI/Control Bar/Menu/Quantization.
Ableton/Live/UG/16 Launching Clips/07 Follow Actions
16.7 Follow Actions
  • The Enable Follow Actions Globally button, next to Ableton/Live/UI/Arrangement View/Button/Back to Arrangement, turns every Follow Action in the Set on or off, which is handy for editing a running clip. It is greyed out when the Set has none.
Ableton/Live/UG/19 Recording New Clips/03 Recording/01 Recording Into the Arrangement
19.3.1 Recording Into the Arrangement
  • Ableton/Live/UI/Control Bar/Button/Arrangement Record starts recording. With Start Playback with Record on (Record, Warp & Launch Settings) it starts at once; with it off, recording waits for Play or a clip launch. Shift-click does the opposite of the setting.
19.3.1 Recording Into the Arrangement
  • Ableton/Live/UI/Control Bar/Switch/Punch-In blocks recording before the Arrangement Loop's start, which protects earlier material and gives a pre-roll. Ableton/Live/UI/Control Bar/Switch/Punch-Out stops it after the loop's end.
19.3.1 Recording Into the Arrangement
  • Recording into the Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop keeps every pass. Undo repeatedly to step back through them, or open the clip: the sample holds all passes, the loop brace marks the last, and moving the markers left plays earlier ones.
Ableton/Live/UG/19 Recording New Clips/03 Recording/02 Recording Into Session Slots
19.3.2 Recording Into Session Slots
  • Set Global Ableton/Live/UI/Control Bar/Menu/Quantization to anything but None so clips are cut on time.
Ableton/Live/UG/19 Recording New Clips/04 Recording in Sync
19.4 Recording in Sync
  • The easiest way is to play with the metronome: turn on Ableton/Live/UI/Control Bar/Switch/Metronome and it ticks once Play is pressed or a clip launches.
Ableton/Live/UG/21 Comping/01 Take Lanes
21.1 Take Lanes
  • Take lanes are hidden in Ableton/Live/UI/Arrangement View/Toggle/Automation Mode; showing or inserting them leaves that mode.
Ableton/Live/UG/26 Automation/02 Recording Automation in Arrangement View
26.2 Recording Automation in Arrangement View
  • Ableton/Live/UI/Control Bar/Button/Arrangement Record starts transport and recording; then changes to tempo, mixer and devices are recorded.
26.2 Recording Automation in Arrangement View
  • Press Arrangement Record again to stop recording but keep playing, or Ableton/Live/UI/Control Bar/Button/Stop to stop both.
Ableton/Live/UG/26 Automation/05 Viewing Automation/02 Viewing Automation in Arrangement View
26.5.2 Viewing Automation in Arrangement View
  • Turn on Ableton/Live/UI/Arrangement View/Toggle/Automation Mode above the track headers, or press A, to open each track's main automation lane.
Ableton/Live/UG/26 Automation/09 Additional Tips for Working with Automation/02 Locking Envelopes in Automation Lanes
26.9.2 Locking Envelopes in Automation Lanes
  • Moving an Arrangement clip normally moves its automation. Ableton/Live/UI/Arrangement View/Toggle/Lock Envelopes, or Options → Lock Envelopes, keeps automation at its timeline position instead.

28.3 Matching Sound to VideoTo fit music to edits or hit points:
  • Optionally loop a section with the Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop.
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link/01 Setting up Link and Link Audio
37.1.1 Setting up Link and Link Audio
  • The Link toggle sits in the Ableton/Live/UI/Control Bar. Set Show Link Toggle to Hide to remove it.
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link/02 Using Link
37.1.2 Using Link
  • With at least one peer connected and the transport stopped, Ableton/Live/UI/Control Bar/Field/Arrangement Position shows a progress bar for the global launch quantization. After you press play, Live waits for the bar to complete.
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/02 Synchronizing via Tempo Follower/01 Setting Up Tempo Follower
37.2.1 Setting Up Tempo Follower
  • Turn on Show Tempo Follower Toggle to put a Follow button with the tempo controls in the Ableton/Live/UI/Control Bar. Pressing Follow starts listening; Tempo Follower does not run while the button is hidden.
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI/02 Synchronizing Live to External MIDI Devices
37.3.2 Synchronizing Live to External MIDI Devices
  • To follow an external sequencer, set it up to send sync and enable it as a sync source in the Tempo & MIDI Settings. An EXT button then appears in the Ableton/Live/UI/Control Bar; turn it on, or use Options → External Sync. The upper LED beside EXT flashes when usable sync arrives.
37.3.2 Synchronizing Live to External MIDI Devices
  • Live accepts song position pointers, so it jumps when the host jumps. With Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop on, positions wrap into the loop.
Ableton/Live/UG/38 Computer Audio Resources/01 Managing the CPU Load/01 The CPU Load Meter
38.1.1 The CPU Load Meter
  • The CPU meter in the Ableton/Live/UI/Control Bar compares the time Live takes to compute one audio buffer with the time that buffer takes to play. 50% means computing runs twice as fast as playback; over 100% is possible.
Ableton/Live/UG/38 Computer Audio Resources/03 The Overload Indicator
38.3 The Overload Indicator
  • The Overload indicator in the Ableton/Live/UI/Control Bar shows "Disk" when the disk falls behind and, once CPU warnings are on, "CPU" when the processor is overloaded.
Ableton/Live/UG/41 Accessibility and Keyboard Nav/04 Navigating in Live/01 Navigate Menu
41.4.1 Navigate Menu41.4.1.1 Control Bar — Option+0 (Mac) / Alt+0 (Win)
  • The Ableton/Live/UI/Control Bar groups project settings, transport, tools and status views. Tab through the groups with Speak Help Text on to hear what each does. Focus returns to the last control used.
41.4.1 Navigate Menu41.4.1.2 Session View — Option+1 (Mac) / Alt+1 (Win)
  • Clip slots — tracks run top to bottom, scenes left to right. Cmd+Shift+M (Mac) / Ctrl+Shift+M (Win) inserts an empty MIDI clip; Enter launches the selected clip, following the Ableton/Live/UI/Control Bar/Menu/Quantization setting. Return tracks show slots that cannot hold clips.
41.4.1 Navigate Menu41.4.1.3 Arrangement View — Option+2 (Mac) / Alt+2 (Win)
  • In Ableton/Live/UI/Arrangement View:
41.4.1 Navigate Menu41.4.1.3 Arrangement View — Option+2 (Mac) / Alt+2 (Win)
  • Locators — arrow to a spot, Tab to Ableton/Live/UI/Arrangement View/Button/Set Locator and press Enter; Tab / Shift+Tab move between locators; Delete removes one.
