Linked references: Logseq/Entity/Definition

Logseq/Entity
Logseq EntityTerms
  • Entity definition — the documentation page for a category of entities that share the same modeling rules. Each entity definition page describes how to recognize, name, and create instances of that kind; individual pages that meet those rules are its instances. Each entity definition page is itself an entity, modeled by Logseq/Entity/Definition.
Logseq EntityFinding the entity definitions
  • Every entity definition page carries logseq-entity:: [[Logseq/Entity/Definition]], so the list of entity definitions is the backlinks of Logseq/Entity/Definition — queryable rather than hand-maintained.

DiscussionNaming and placement
  • One Discussion page per subject, at <Subject>/Discussion: Logseq/Entity/Definition/Discussion discusses Logseq/Entity/Definition.
DiscussionPage shape
  • H1 — the subject page's H1 followed by Discussion: - # Music Scale Discussion for Logseq/Entity/Music/Scale, whose H1 is Music Scale. When the subject has no page file, the H1 names the subject in Title Case without the Logseq/ prefix, as - # Entity Hierarchy Discussion does for Logseq/Entity/Hierarchy. Logseq/Entity/Definition/Discussion keeps the H1 codekiln wrote for it.
DiscussionExamples in this garden
